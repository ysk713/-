# 緊急移送症例 取りまとめ

各公館の医務官から届いた「緊急移送症例登録フォーム」（Excel）をまとめて読み込み、一覧・チェック・集計をして、福利厚生室の集計表と同じ形のExcelに書き出すアプリです。

https://ysk713.github.io/-/kinkyu-isou/ をブラウザ（Edge／Chrome）で開くだけで使えます。PCにソフトを入れる必要はありません。
試しに見るときは https://ysk713.github.io/-/kinkyu-isou/?demo （架空の24件。保存はされません）。

## できること

1. **取り込み**：登録フォームのExcel（.xlsx／.xlsm／.xls）を何件でもまとめてドラッグ＆ドロップ（フォルダごとでも可）。福利厚生室の集計表（Summary シート）や、このアプリで書き出したExcelも読み込めます。同じファイルを読み直すと入れ替えます。
2. **一覧・チェック**：1症例1行の一覧。年（**転帰年**＝転帰日の年〔標準〕／**報告年**＝登録した年／**発生年**を切り替え）・移送の実施／中止・文字で絞り込み、見出しを押して並べ替え。症例番号は**ファイル名の先頭の数字**から付けます（例：`0031_PapuaNewGuinea_20190326.xlsx` → 31番。フォームの症例番号欄と違うときは要確認で知らせます）。ファイル名に番号がない症例は、その場で入力するか「空欄の症例番号を振る」で発生日の古い順に付けられます。「詳しく」でフォームの全項目を表示・印刷。
3. **集計**：発生年、症例区分、性別、年齢、転帰、内因性・外因性、内因性分類・外因性分類、医務官の関与、移送方法、発生国、最終移送先の国、報告した公館、キーワードの件数。一覧の絞り込みがそのまま反映されます。
4. **分析**（表の数字を押すと、当てはまる症例の一覧が出ます）
   - **グラフ**：年ごとの件数（内訳を選べる積み上げ棒）、指標の推移（折れ線）、年齢層と性別（ピラミッド）、クロス集計の内訳（横棒の割合）、日数の分布（箱ひげ図）。棒や点にマウスを載せると数字が出ます。年の基準は転帰年・報告年・発生年から選べます。「③ 集計」にも転帰年ごとの件数（内因性・外因性の内訳）のグラフ。
   - **主な指標**：移送の実施率、日本へ／第三国へ移送した割合、2区間以上の移送、エアアンビュランスの使用、死亡、外因性、医務官が主導した割合。全体と、発生年・発生地域・症例区分などの切り口ごと（年ごとの推移も見られます）。割合の分母は、その項目が記入されている症例。
   - **クロス集計**：縦と横に好きな切り口を選ぶ（例：発生地域 × 最終移送先、発生年 × 病因の分類、年齢層 × 転帰）。件数・行ごとの割合を色の濃さで表示し、Excelにも保存できます。
   - **日数**：発生から転帰まで・発生から報告までの日数（中央値・四分位・最小〜最大）。切り口ごとにも。
   - **自由記載によく出てくる話題**：ロジスティックな問題点・内容などから「保険」「費用・デポジット」「旅券・ビザ」「空港・航空機」「夜間・休日」「病院の受け入れ」「通訳」「家族」「連絡」「治安・災害」を拾い、該当箇所を色付きで表示。好きな言葉でも探せます。
   - 発生国・移送先の国は、世界医療情報マップの国名一覧（`world-health-map/data/countries.json`）で地域（アジア・大洋州・中東・アフリカ・欧州・北米・中米・カリブ・南米）に分けます。都市名だけのときなどは「国名から判定できず」になります。
5. **書き出し**：次の4シートのExcel。
   - **Summary**：福利厚生室の集計表と同じ列（AQ〜DW）・同じ番号（実施＝1、男＝1、病因は TRUE/FALSE など）。そのまま集計表に貼り付けられます。
   - **一覧**：文字で読める一覧とチェック結果。
   - **集計**：③の表。
   - **主な指標**：④の主な指標を全体と発生年ごとに。

## チェックする内容

- **要修正**：必須項目の空欄（所属・氏名・報告年月日・発生年月日・発生国・イニシャル・性別・症例区分・転帰・診断・内因性／外因性・要約など）、存在しない日付、未来の日付、転帰日や報告日が発生日より前、症例番号の重なり
- **要確認**：報告年月日が2018年（登録の始まり）より前、症例発生年が1990年より前、発生年が年齢から計算した生まれ年とほぼ同じ・発生日と転帰日が1年以上離れている（生年月日を入れた間違い）、転帰日が報告年月日より後（年の入れ間違い）、イニシャルが1文字でない（名前そのものが入っていないか）、内因性・外因性と分類のチェックの食い違い、移送方法と移送先の片方だけの入力、「その他」の内容の書き漏れ、移送実施なのに移送先が空欄、二重登録（発生日・発生国・イニシャル・年齢・性別が同じ）、自由記載に人名（「〇〇様」など）・旅券番号・生年月日・電話番号らしきものがある

## 読み取りのしくみ

フォームの入力欄（E9＝報告医務官の所属 など）を直接読み、空なら3行目（AQ3〜DW3。フォームの各項目が数式やボタンのリンクで集まっている行）の値を使います。ラジオボタン・チェックボックスの選択は3行目のリンク先セルから読みます。添付画像は読み込みません。

## データの扱い

- 読み込み・チェック・集計・書き出しはすべてブラウザの中だけで行い、外部には送りません（ページの Content-Security-Policy で外部への通信を禁止しています）。
- 読み込んだ症例はそのPCのブラウザ（localStorage）に保存されます。別のPC・ブラウザでは見えません。控えは書き出したExcelで残してください（このアプリで読み込み直せます）。
- 登録データは医務官と福利厚生室の一部だけが見る前提です。書き出したExcelの保存先・送り先に注意してください。
- 登録フォームのひな形や実際の症例は、このリポジトリには入れていません。

## 作り直し・テスト

```bash
python3 kinkyu-isou/build.py
```

```bash
node kinkyu-isou/tests/test_core.js
```

本体は `src/app.html`（画面）と `src/core.js`（読み取り・チェック・集計・書き出し）。`build.py` が SheetJS（`geppou/lib/xlsx.full.min.js`）と一緒に `index.html` に埋め込みます。

## 年について

年は**転帰日**を基準にします（一覧の並び・絞り込み、集計の「転帰年」、分析の主な指標の切り口、書き出しの「主な指標」シート）。症例発生年月日には、生年月日が間違って入っていることがあるためです（例：発生年月日が1987年で、年齢37歳）。

- 転帰日が空欄の症例は、転帰年では「（未記入）」になります。
- 登録した年で数えたいときは「報告年」、参考として「発生年」にも切り替えられます。2018年より前に起きた症例をさかのぼって登録したものがあるため、発生年や転帰年には2018年より前の年も出ます。
- 「発生から転帰までの日数」は、1年を超えるもの（生年月日が入っている可能性）を除いて計算します。
