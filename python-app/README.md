# Python 練習帳

ブラウザだけで Python を書いて実行できる学習アプリです。インストールは不要で、`index.html` をブラウザで開けば使えます（初回は Python 実行環境 Brython を CDN から読み込むため、ネット接続が必要です）。

## できること

- **レッスン 18回**（基礎編 → データと関数 → 中級編）
  print、変数、文字列、型変換と input、if、リスト、for、while、辞書、タプルと集合、関数、内包表記、例外処理、クラス、標準ライブラリ、ジェネレータ、デコレータ、総合演習
- **例のコードをその場で実行**して、書き換えて試せる
- **自動採点つきの演習**：複数の入力パターンで判定し、どこが違うかを表示
- **ヒントと解答例**
- **確認クイズ**（各レッスン1問）
- **自由練習**：好きなコードを実行できるエディタ（サンプル付き）
- エラーが出たときは、行番号と日本語のヒントを表示
- 進み具合と書いたコードはブラウザに自動保存

## エディタの操作

| 操作 | キー |
|---|---|
| 実行 | Ctrl + Enter（Mac は Cmd + Enter） |
| インデント | Tab / Shift + Tab |
| `:` の後で改行 | 自動でインデントが入る |

## 注意

- 無限ループを実行するとページが固まります。そのときは再読み込みしてください（コードは実行前に保存されています）。
- ファイルの読み書きやネットワーク通信など、ブラウザ内では動かない機能があります。
