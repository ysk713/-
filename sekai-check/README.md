# 世界の医療事情 原稿チェッカー

外務省「世界の医療事情」の国別原稿（Word）と別添４（ワクチン接種可能な医療機関・Excel）を、原稿作成要領（別添１）・訓令別表（別添２）・別添３に照らしてチェックし、医務官への照会メールと、見え消し＋コメント付きの原稿（`☆【体裁修正済み】[国名].docx`）を作ります。**最終判断は必ず人が行ってください。**

## 使う場所は2つ

| | GitHub Pages 版 | claude.ai 版 |
|---|---|---|
| 開き方 | **https://ysk713.github.io/-/sekai-check/** | https://claude.ai/artifact/DUD5HnvRYf4v5jevpQHaQh |
| 外部への通信 | 一切しない（ページで禁止） | しない（Claudeで内容を確認するときだけ、確認の上で原稿を送る） |
| Claudeで内容を確認 | 使えない | 使える |
| ウェブサイトの自動確認 | 使えない（リンクを開いて確認） | 使えない |
| 照会メールの.eml保存 | できる | できない（本文をコピーしてOutlookに貼り付け） |

## 使い方

1. **チェック**：原稿（.docx）と別添４（.xlsx）をまとめてドラッグします。同じ公館の原稿と別添４は、照会メールで1通にまとまります。
2. 指摘一覧で、医務官に照会するものに「照会」のチェックを入れます（内容面の指摘は最初からチェック済み、表記の指摘は外してあります）。
3. **体裁修正版（docx）を作成**：表記の誤りは見え消しで直して【修正】コメントを、内容面は本文を変えずに【確認】コメントを付けます。差し戻し推奨の原稿（①欠損が多い）は作らずに知らせます。
4. **連絡先確認**：原稿と別添４のウェブサイト・電話番号の一覧。確かめた結果を記録すると、「つながらない」ものは照会メールに入ります。
5. **照会メール**：公館ごとに1通。本文を確認・修正してOutlookへ。
6. **進捗**：公館ごとの状態（未照会・照会中・回答受領・完了）。

宛先（医務官名・メールアドレス）は［設定・宛先］に貼り付けます。医務官名を含むため、宛先データはこのリポジトリには置かず、各自のブラウザ内にだけ保存されます。

## チェックの中身

- 全てのチェックは、未承認の見え消しを全て承諾した後の本文に対して行います（他の人の見え消しが多い原稿で「本文が欠けて見える」誤検出を防ぐため）。
- ① 致命的な欠損（見出しだけで本文なし、空白段落の連続、表の単位だけのセル、数字の脱落、年の数字の欠落、URLの途中切れ）
- ② 要領の必須事項（項目１〜１０の各節ごと。（５）の疾患の（７）への反映、マラリア、一口メモの必須語彙、項目（３）と訓令別表の整合 など）
- ③ 文字種（ラテン文字に混じったキリル文字等、赤字の残留）
- ④ 表記（ヶ月、土日、全角カンマ、丸数字、電話番号の書式 など）
- ルールは［設定・宛先］の表で追加・変更できます（年度が変わったら要領に合わせて直す）。
