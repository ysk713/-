# 頻出数字・法改正まとめ（直前確認用）

[← 目次に戻る](README.md)

> 2026年10月時点の内容です。施行日が未確定の改正は、受験前に厚生労働省等の公式情報で確認してください。

## 労働時間・面接指導

| 項目 | 数字 |
|---|---|
| 時間外労働の上限（原則） | 月45時間・年360時間 |
| 特別条項の上限 | 年720時間、複数月平均80時間以内、単月100時間**未満**（時間外＋休日）、月45時間超は年6か月まで |
| 長時間労働者の面接指導（一般） | 時間外・休日労働 月80時間超＋疲労の蓄積＋**申出** |
| 研究開発業務従事者 | 月100時間超で申出なしに義務 |
| 高度プロフェッショナル | 健康管理時間の週40時間超部分が月100時間超で義務 |
| 産業医への情報提供 | 月80時間超の労働者の氏名・時間等 |
| 面接指導結果の記録 | 5年保存 |
| 労働時間の状況の記録 | 3年保存 |

## ストレスチェック

| 項目 | 内容 |
|---|---|
| 実施義務 | 常時50人以上の事業場（50人未満は現在努力義務。2025年改正で義務化予定） |
| 頻度 | 1年以内ごとに1回 |
| 実施者 | 医師、保健師、研修修了の歯科医師・看護師・精神保健福祉士・公認心理師 |
| 実施事務従事者になれない者 | 解雇・昇進・異動に直接の権限を持つ者 |
| 調査票 | 職業性ストレス簡易調査票（57項目／簡略版23項目） |
| 面接指導 | 高ストレス者の**申出**により実施 |
| 期限の目安 | 申出：通知後おおむね1か月以内／面接指導：申出後おおむね1か月以内／意見聴取：面接後おおむね1か月以内 |
| 記録の保存 | 結果（事業者提供分）5年、面接指導結果5年 |
| 集団分析 | 努力義務、10人未満は原則全員同意が必要 |
| 労基署への報告 | 年1回（50人以上） |

## 体制

| 項目 | 内容 |
|---|---|
| 衛生委員会 | 常時50人以上で設置、毎月1回以上開催、議事録3年保存 |
| 産業医 | 50人以上で選任、1,000人以上（有害業務500人以上）で専属、3,000人超で2人以上 |
| 産業医の勧告 | 衛生委員会に報告、記録3年保存 |
| 推進担当者 | 衛生管理者等・常勤保健師等から選任が望ましい、人事権を有する者は不適当 |

## 労災認定（精神障害・2023年改正）

- 要件：①対象疾病の発病 ②発病前おおむね6か月の業務による強い心理的負荷 ③業務以外の要因によらない
- 極度の長時間労働：発病直前1か月におおむね160時間超、または3週間におおむね120時間以上
- 追加された出来事：カスタマーハラスメント、感染症等の危険性の高い業務
- 悪化：特別な出来事がなくても、強い心理的負荷で悪化した場合は悪化部分を認める

## 傷病手当金

- 待期3日（連続）→ 4日目から
- 標準報酬日額相当額の3分の2
- 支給開始日から**通算**1年6か月（2022年1月〜）

## ハラスメント

- パワハラ防止措置義務：大企業2020年6月、中小企業2022年4月
- 3要素：優越的な関係／業務上必要かつ相当な範囲を超える／就業環境が害される
- 6類型：身体的な攻撃、精神的な攻撃、人間関係からの切り離し、過大な要求、過小な要求、個の侵害
- 2025年改正：カスタマーハラスメント対策の措置義務化（施行日は要確認）

## 主要な判例

| 判例 | ポイント |
|---|---|
| 電通事件（最判2000年） | 業務による疲労・心理的負荷の過度な蓄積を防ぐ注意義務 |
| 東芝事件（最判2014年） | 精神的健康情報の不申告を理由とする過失相殺は不可 |

## 職場復帰支援の手引き 5ステップ

1. 病気休業開始及び休業中のケア
2. 主治医による職場復帰可能の判断
3. 職場復帰の可否の判断及び職場復帰支援プランの作成
4. 最終的な職場復帰の決定
5. 職場復帰後のフォローアップ

→ 原則は元の職場へ復帰。試し出勤（模擬出勤・通勤訓練・試し出勤）は処遇・労災の取扱いを事前に明確化。
