# 医務官月報 取りまとめアプリ

各国の在外公館から届く医務官月報（甲表・乙表・丙表）を読み込み、集計・地図化・Wordレポート化するアプリです。
ブラウザで操作しますが、**手元のPCで動き、データは `data/geppou.db` にのみ保存されます**（外部送信なし）。

## 起動

- Windows: `start_windows.bat` をダブルクリック（初回のみ必要なライブラリを自動インストール）
- Mac: `start_mac.command` をダブルクリック
- 手動: `pip install -r requirements.txt` → `streamlit run app.py`

ブラウザが自動で開きます（開かなければ http://localhost:8501 ）。Python 3.10 以上が必要です。

## 画面

| メニュー | できること |
|---|---|
| 📥 取り込み | 月報PDFを複数まとめて読み込み → 読み取り結果を表で確認・修正 → 保存。医務官配置表（xlsx）の登録もここ |
| 📊 月次ダッシュボード | 提出数・受診者数（前月比）、地域別グラフ、公館別表、**未提出公館**、診断名トップ10 |
| 🗺️ 世界地図 | 疾病の流行状況（国ごとの最多疾病分類で塗り分け）、受診者数、丙表から検出した感染症・災害・治安・邦人保護、**巡回健診の移動**、**医務官の異動** を重ねて表示。分類別の分布図も |
| 📝 公館別5行サマリー | 各公館を5行（受診者数／主な疾病／医療・感染症／邦人保護／その他）で要約。自由に編集して保存可 |
| 🚑 巡回健診 | 丙表の「巡回」記述から 出発公館→巡回先・期間 を自動抽出。表で修正・追加でき、地図に矢印表示 |
| 👤 医務官の異動 | 月報ヘッダー（無ければ配置表）の医務官名を月ごとに比較して交代を検出。同じ氏名が別公館に現れたら前任地→新任地の矢印 |
| 📈 月ごとの推移 | 受診者数・疾病分類の推移（全体／地域／公館） |
| 📄 Wordレポート | 表紙・目次・全体概況・世界地図・統計表・巡回/異動・公館別5行サマリー入りの .docx を出力 |
| ⚙️ 設定 | 自動分類できなかった病名の分類設定、月単位のデータ削除 |

## 読み取りの仕組みと注意

- 月報PDFは2形式に対応: 中身がZIP（ページ画像＋OCRテキスト）のPDF／通常のPDF。
  OCRテキストのないページは取り込み画面に画像を表示するので、目視で数値を補ってください。
- 公館名・医務官名・受診者数は**甲表1ページ目のヘッダー**から読みます（配置表は名前が取れない場合の補完と未提出チェック用）。
- 乙表は「病名(件数)」の組を抜き出し、キーワードでICD-10の章に再分類します（`geppou/icd.py`）。
  分類できない病名は「設定」画面で割り当てると次回から反映されます。
- 地域区分は アフリカ／アジア・大洋州／ヨーロッパ（中央アジア・ロシア含む）／中東（トルコ含む）／米州。
  公館の追加・地域の変更は `geppou/posts.py` を編集します。
- 巡回健診・出来事（感染症など）はキーワードによる自動検出なので、取りこぼし・誤検出は画面で直してください。

## 5行サマリーのAI生成（任意）

既定では月報データから機械的にサマリーを作ります。環境変数 `ANTHROPIC_API_KEY` を設定して起動すると、
サマリー画面に「AIで生成」ボタンが出て Claude で要約できます。**その公館の月報本文が外部APIに送信される**ため、
組織の情報管理規程で許可されている場合のみ使ってください。

## 動作確認用ダミーデータ

`python sample/make_sample.py` で `sample/files/` に架空の月報3か月分（15公館）と配置表が作られます。
