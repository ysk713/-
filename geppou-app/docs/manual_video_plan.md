# 使い方マニュアル動画（作成メモ）

依頼（2026-10-25）：使い方マニュアルを**動画**で作る。月曜日（2026-10-26〜）に職場のPCで
スクリーンショット（または画面録画）を撮り、それを素材にして仕上げる。

## 動画の流れ（台本の骨子）

| # | 場面 | 素材 | 誰が撮るか |
|---|------|------|-----------|
| 1 | タイトル「医務官月報 取りまとめ 使い方（月報の取り込み）」 | 文字のみ | こちらで作成 |
| 2 | **医務官執務参考ページ**を開く | スクリーンショット | 職場PCで撮影 |
| 3 | 月報のフォルダを**同期**する（同期ボタンの位置を矢印で示す） | スクリーンショット（同期前・ボタン・同期後） | 職場PCで撮影 |
| 4 | **エクスプローラー**に同期したフォルダが表示される | スクリーンショット | 職場PCで撮影 |
| 5 | フォルダを開き、**分析したい月報**（例：202608 の各公館の月報PDF）を選ぶ（Ctrl+A／Shift+クリック） | スクリーンショット | 職場PCで撮影 |
| 6 | アプリ（https://ysk713.github.io/-/geppou/）を開き、「取り込み」タブへ | 画面録画 | こちらで作成（デモ） |
| 7 | 選んだ月報を、エクスプローラーからアプリの枠へ**ドラッグ＆ドロップ** | 職場PCの画面録画が理想。なければスクショ2枚（掴む・離す）＋アプリ側はこちらの録画 | 両方 |
| 8 | 読み込み結果（公館数・未提出・パスワード付きPDFは自動で開く）→ ダッシュボード | 画面録画 | こちらで作成（デモ） |
| 9 | 終わりに：データはこのPCのブラウザだけに保存、書き出しは医務官のみアクセス可のフォルダへ | 文字 | こちらで作成 |

## 月曜日に職場PCで撮ってほしいもの

1. 医務官執務参考ページのトップ（月報フォルダへの入り口が見える状態）
2. 同期ボタン（またはメニュー）を押す前・押した後
3. エクスプローラーの左側に同期フォルダが出ている画面
4. 月報フォルダの中（ファイル一覧）と、複数ファイルを選択した状態
5. できれば：Windows の画面録画（Win+Alt+R＝Xbox Game Bar、または Snipping Tool の録画）で
   「ファイルを選ぶ → アプリへドラッグ → 読み込み完了」まで一続きで（30秒程度）

※ 撮影時の注意：職員名・公館名以外の個人情報、ページ内の機微な情報が写らないようにする
  （写った部分はこちらでぼかしを入れられる）。動画は省内の医務官向けに限って共有する。

## こちらで用意するもの

- アプリ側の操作の画面録画（デモデータ。取り込み画面・ドラッグ＆ドロップ後の読み込み・ダッシュボード・地図）
- 字幕（各場面の説明文）、矢印・枠の強調、場面のつなぎ
- 仕上げ：MP4（1280×720 程度）。素材が届いたら差し替えて書き出す
