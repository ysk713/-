# 80人シミュレーション（自動実行）の結果と対応

`python3 geppou-app/sim/sim80.py` で、80人の架空の医務官（自分の公館60人・地域の取りまとめ14人・全公館の取りまとめ6人）が、それぞれ別のブラウザで月報を取り込み、全タブ・PDF・AI用テキスト・バックアップ・開き直しまで操作した。読み込んだ架空の月報は合計4,319件。

- 結果の一覧：`geppou-app/sim/results/sim80_20261031_0404.md`（1回目・80人）、`sim80_20261031_0411.md`（直したあと、問題の出た10人の再実行）
- 問題がなかったこと：画面のエラー0件、外部への通信0件、開き直してもデータは残る、PDFは最大9.2MB（10MB未満）、PDF作成は中央値4.7秒、1,440件の読み取りは33秒、使った保存容量は最大45MB

## 見つかった問題と対応

| 重さ | 問題 | 起きた人 | 対応 |
|---|---|---|---|
| 高 | **名前と大きさが同じで中身の違う月報が、重複として落とされる**。各国のフォルダにある「月報.docx」を順に入れると、たまたま同じ大きさのファイルが入らない（全公館の取りまとめで720件中574件、地域の取りまとめで54件中10〜13件が欠けた） | 6人 | **直した**：名前と大きさが同じときは中身も比べる。テストを追加 |
| 中 | **AI分析・設定のタブで画面が横にはみ出す**（ⓘの見えない吹き出しが画面の端から出ていた） | 試行で全員 | **直した** |
| 低 | **1024×768の画面・タブレットで、タブの後ろの方（PDF・AI分析・設定など）が画面に入らない** | 26人 | **直した**：狭い画面では、選んでいないタブを絵だけにする |
| 中 | ファイル名に年月がない（フォルダ名にだけ月がある）と、全行が「要確認」になる | 14人 | 本文から月を読めているので、安全のための確認として残す。ファイル名の付け方の統一（国名_YYYYMM）を案内する |
| 中 | 処理の遅いPC（4倍遅い想定）で、開くときに約2秒、画面が固まる（ふつうのPCでは0.5秒） | 16人 | 未対応。グラフの部品（大きい）を、使うときに読み込む方式にすると軽くなる見込み |
| 低 | 読めないPDF（別のパスワード）が混じると、その1件で最大1分待ってから次に進む | 1人 | 仕様どおり（1分で飛ばす）。待ち時間の短縮を検討 |

Edge の案内が出ないように見えた件は、シミュレーションの確かめ方の問題だった（案内は開いて1.5秒後に出る）。
