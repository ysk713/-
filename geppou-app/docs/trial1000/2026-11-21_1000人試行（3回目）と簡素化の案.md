# 1000人試行（3回目）と、操作・画面を簡素にする案

- 日付：2026-11-21　対象：v=328（パソコンのみ。1366・1920・1024・1280px、ライト・ダーク）
- 今回から、前回まで使っていない病名140語（14診療科×10語）を新たに混ぜ、合わせ込んでいない語での正しさも測った。

## 結果
- 止まる・エラー・外部への通信・横はみ出し：すべて 0。1024px でもタブは1行。
- 病名の分類（期待とのずれ）
  - 前回までの182語：4%
  - 初めての140語：試行時 8%（11語）→ 略語・英語などを直して 4%
  - 残りはすべて判断の分かれるもの（咽頭痛・嗄声・腹痛・頭痛は臓器の章、乳腺腫瘤・乳腺炎は ICD-10 の N63・N61、食中毒は A05 で感染症、一過性脳虚血発作は循環器、鳥インフルエンザは感染症、しびれは神経）
  - 「AFP高値」が AF（心房細動）にならないよう、略語（HTN・AF・URI・DM・GERD・COPD・UTI・PCOS）は単語として出たときだけ照合するようにした。既存の1293語の分類は変わっていない。
- 速さ（中央値）：タブ 0.09〜0.28秒、地図 0.58秒、レポートの章 1.6秒、PDF 5.6秒（最大15秒）、Word 2.1秒。前回より1〜2割遅いが、テスト機の混み具合で変わる範囲（デザインと無関係な計算も同じだけ遅い）。

## 簡素化の案（ユーザーが選ぶ）
1. タブを13→8に：緊急移送＋邦人対応＝「邦人保護」、巡回健診＋医務官の異動＝「医務官」、推移→「統計」の中へ、AI分析→「レポート作成」の中へ。
2. 地図のおまけ機能をやめる：ハイライト・ツアー、タイムラプス、飛行機アニメ、国歌の録音（設定のカードも）、音。
3. 統計は「よく使う集計」だけ最初に見せ、検定・推定・自由集計は「詳しい分析」を開いたときだけ。
4. 設定は「よく使う設定」（自分の公館・バックアップ・在籍人数）だけ見せ、ほか（OCRの確認・動作の記録・オフライン・病名のまとめ方・分類の手動設定・AIの送り先）は「詳細設定」に。
5. 上の帯は「バックアップ」と「対象月」だけ。使い方・不具合報告・月報くんフォルダは設定へ。
6. 実際の関心を測る：どのタブ・ボタンを使ったかを、このパソコンの中だけで数える（外部には送らない）。設定で見られるようにし、1〜2か月後に使われていないものを外す。
