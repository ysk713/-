## 2. 問題点

### 高

### 中
**中-1　概況の「〇〇医務官」で、空白のない氏名は名字を先頭2文字と決めつけるため、3文字の名字が切れる**
- 11-19 の変更で、概況用の文章の医務官は配置表の名前から名字を取り出して「〇〇医務官（国名）」と載せる。名前に空白があれば正しいが、空白がないと先頭2文字を名字とみなすため、3文字の名字が切れて、別人のような名前でAIに渡る。
  - 佐々木一郎 → 「佐々医務官」、長谷川花子 → 「長谷医務官」、五十嵐守 → 「五十医務官」、東海林修 → 「東海医務官」
  - 1文字の名字は逆に「林一 → 林一医務官」（全部）、英字の名前は「Dr. Smith → Dr.医務官」になる
- 依頼文は「名前は資料の表記どおりに書く」としているので、AIの回答の交代一覧・巡回健診の医務官名がそのまま間違う。
- 再現：デモの画面で officerSurname('佐々木一郎')、officerSurname('長谷川花子')。
- 望み：空白のない名前は、配置表のふりがな（姓と名の間の空白）から名字の長さを決める。ふりがなもないときは名字を推し量らず、氏名をそのまま使う（または取り込みの確認画面で「姓と名の間に空白を入れてください」と知らせる）。
