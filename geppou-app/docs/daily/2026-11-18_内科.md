## 2. 問題点

### 高
**高-1　「否定」「除外」「陰性」「なし」「既往」が付いた病名が、その病気として数えられる**
- 乙表の病名に「〇〇否定」「〇〇除外」「〇〇陰性」「〇〇なし」「〇〇の既往」と書くと、否定された病名（または過去の病名）がそのまま分類され、病名のまとめ（上位の病名・感染症の流行）にも、その病気の1件として入る。
  - 発熱（デング熱否定）→ 感染症／「デング熱」、マラリア除外・マラリア陰性 → 感染症／「マラリア」、麻疹否定 → 感染症／「麻疹」、COVID-19陰性 → 感染症／「新型コロナウイルス感染症」、疥癬否定 → 感染症／「疥癬」
  - 胸痛（心筋梗塞否定）→ 循環器／「心筋梗塞」、腹痛（虫垂炎否定）→ 消化器／「虫垂炎」、骨折なし → 外傷／「骨折」
  - 妊娠反応陰性・妊娠否定 → 妊娠・出産、希死念慮なし → 精神・行動、結核の既往・うつ病の既往 → それぞれの病気
- 熱帯の公館では「発熱（マラリア陰性）」「発熱（デング熱否定）」のように書くことが多く、デング熱・マラリアの件数が実際より多く出て、流行と見誤るおそれがある。心筋梗塞・虫垂炎・妊娠・精神も、否定した例が数に入る（妊娠・精神は件数の少ない公館で個人が推測されやすい分類でもある）。
- 再現：デモの画面で classify('発熱（デング熱否定）')・groupOf('発熱（デング熱否定）')、classify('胸痛（心筋梗塞否定）') など。
- 望み：「否定」「除外」「陰性」「なし」「異常なし」「既往」「r/o 否定」の付いた病名は、その病名では数えない（括弧の外の症状〔発熱・胸痛など〕で分類し、括弧の外がなければ「検査・Z」や「症状・徴候」にする）。「疑い」は、確定とは分けて数えられるようにする（例：「デング熱（疑い）」は件数の横に「うち疑い〇件」）。
