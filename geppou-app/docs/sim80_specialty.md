# 専門科の異なる医務官から見た「月報くん」への指摘（机上シミュレーション）

医務官は内科・外科・小児科・精神科・皮膚科などさまざまな専門の医師である。それぞれの科の医師が、月報くんの集計・グラフ・PDFを見たときに言いそうなことを洗い出した。

- **アプリで対応できる**：今の月報（甲表・乙表・丙表）の情報から作れる。
- **様式が要る**：今の月報には、その情報（年齢・部位・重症度など）がない。様式の変更か、丙表への書き方の統一が要る。

## 皮膚科

| 指摘 | 対応 |
|---|---|
| **シェーマ（人体図）で、どこに多いか見たい**。足白癬・手湿疹・顔面の皮膚炎・陰部・体幹など | アプリで対応できる（一部）。病名に含まれる部位の語（足・手・顔面・頭部・陰部・体部・爪 など）から部位を推定し、人体図に色で示す。部位の書いていない病名（湿疹・蕁麻疹 など）は「部位不明」として件数だけを出す |
| 「皮膚」が1つの大分類で、中身が分からない。湿疹・皮膚炎、皮膚の感染（白癬・とびひ・蜂窩織炎）、虫刺され、日光・熱による皮膚障害、蕁麻疹に分けたい | アプリで対応できる。病名から小分類を付ける（大分類の中の内訳グラフ） |
| 熱帯の皮膚疾患（皮膚幼虫移行症・皮膚リーシュマニア症・ハエ幼虫症・疥癬・トゥンガ症）が、地域別に見えない | アプリで対応できる。「熱帯・渡航関連の皮膚疾患」として地図・地域別に示す |
| 写真がないと診断の妥当性が分からない | 対象外。健康情報が増えるので、写真は月報に入れない方がよい |

## 内科（総合）

| 指摘 | 対応 |
|---|---|
| 生活習慣病（高血圧・糖尿病・脂質異常症・高尿酸血症）を、まとめた1本の推移で見たい。単身赴任の多い公館で増えていないか | アプリで対応できる。「生活習慣病」のまとまりを作る |
| 受診の「延べ」だけでなく、慢性疾患の継続受診と新規の受診を分けたい | 様式が要る |
| 年齢層が分からないと、比べようがない | 様式が要る（甲表に年齢区分がない） |

## 感染症科

| 指摘 | 対応 |
|---|---|
| 届出対象の感染症（一類〜五類相当）や輸入感染症（マラリア・デング熱・腸チフス・狂犬病曝露）を、他の病名と区別して見たい | アプリで対応できる。注目する感染症の一覧（設定で足し引き可）で、いつもより多いときに知らせる |
| 狂犬病の曝露後予防（PEP）の件数と、ワクチン・免疫グロブリンが手に入る国かどうかを並べたい | アプリで対応できる（件数）。手に入るかどうかは、丙表の記載か別の資料が要る |
| 疑い例と確定例が混ざる | 様式が要る（「疑い」の書き方の統一）。今は「（疑い）」を同じ病名として数えている |

## 小児科

| 指摘 | 対応 |
|---|---|
| 職員と家族の区別はあるが、家族の中の子どもが分からない。小児の感染症（RS・手足口病・水痘・麻疹）の流行は子どもの数で見たい | 様式が要る（家族のうち小児の数） |
| 予防接種の件数（定期・任意・渡航ワクチン）を、子どもの接種の遅れの把握に使いたい | アプリで対応できる（Z の検診・予防接種の内訳を出す） |
| 発達・学校（現地校・日本人学校）に関する相談が見えない | 様式が要る |

## 精神科

| 指摘 | 対応 |
|---|---|
| 精神・行動の障害は、件数が少ない公館では個人が特定されやすい。PDF・AI分析で公館名と一緒に出さないでほしい | アプリで対応すべき。精神・行動は公館別に出さず、地域別だけにする（少ない件数は「3未満」） |
| 不眠・適応障害・うつを、赴任後の月数（赴任直後に多いか）で見たい | 様式が要る（赴任時期）。医務官の異動の月からの経過で見る程度ならアプリで対応できる |
| ストレスチェック・メンタル面談の件数を、受診とは別に見たい | アプリで対応できる（丙表の記載から拾う）。数は書き方次第 |

## 整形外科・外科

| 指摘 | 対応 |
|---|---|
| 外傷を原因で見たい（交通事故・転倒・スポーツ・凍結路面・暴力） | アプリで対応できる（一部）。病名・丙表の語から原因を推定。正確には様式が要る |
| 外傷にもシェーマがほしい（骨折の部位） | アプリで対応できる（一部）。皮膚科と同じ人体図の仕組みで、病名の部位から示す |
| 手術・入院が要った件数（現地で手術できたか、移送になったか）が分からない | 様式が要る。緊急移送の章で一部は分かる |

## 産婦人科

| 指摘 | 対応 |
|---|---|
| 妊娠・出産の件数が少なく、「妊娠・出産」の大分類だけでは何も分からない。現地で出産できたか、一時帰国したかを知りたい | 様式が要る |
| 妊婦の感染症（ジカ・デング・風疹）の流行地域を、妊娠中の家族がいる公館と重ねたい | 様式が要る（妊娠中の家族の有無は個人情報に近いので慎重に） |

## 眼科・耳鼻咽喉科

| 指摘 | 対応 |
|---|---|
| 結膜炎（大気汚染・砂嵐・アレルギー・感染）を、環境の悪い地域と重ねたい | アプリで対応できる。丙表の環境の記載（PM2.5・砂嵐）と結膜炎・鼻炎・副鼻腔炎の件数を並べる |
| 「耳」の大分類に、鼻・のどの病名がどう入っているか分からない | アプリで対応できる。大分類の中身（病名の一覧）を、どの画面からも開けるようにする |

## 救急・集中治療

| 指摘 | 対応 |
|---|---|
| 緊急移送の章に、発症から移送までの時間、移送手段（エアアンビュランス・定期便）、費用の情報がほしい | 様式が要る（移送の報告の項目を決める） |
| 現地の医療機関の受け入れ能力（ICU・CT・輸血）を、国ごとに一覧にしたい | 丙表の記載から一部は拾える。本格的には「世界の医療事情」と連携 |

## 公衆衛生・産業医

| 指摘 | 対応 |
|---|---|
| 受診者数を、公館の職員・家族の人数で割った「受診率」で比べたい。延べの件数だけでは、大きい公館ほど多いのは当然 | 公館ごとの在籍人数が要る（配置表に人数の欄を足す、または設定で入れる） |
| 健康診断・予防接種・ストレスチェックの実施率 | 在籍人数が要る |
| 季節の補正、前年同月比はある。地域の流行情報（WHO・CDC）と並べたい | 外部への接続になるので、アプリでは行わない（個人情報を外に出さない方針） |

## まとめ：すぐにアプリで対応できる候補

1. **人体図（シェーマ）**：病名の部位の語から、皮膚・外傷の部位を人体図に示す（部位不明は件数だけ）。
2. **大分類の中の内訳**：皮膚・外傷・感染症などを小分類に分けたグラフ。
3. **注目する感染症・生活習慣病のまとまり**：一覧を設定で選び、いつもより多いときに知らせる。
4. **精神・行動の保護**：PDF・AI分析で公館別に出さず、地域別だけにする。
5. **予防接種・検診（Z）の内訳**。

様式（月報の書式）の変更が要るもの：年齢区分・家族のうち小児の数、在籍人数、外傷の原因、移送の詳細、慢性疾患の継続受診と新規受診の区別。
