# 決定事項（ユーザーが決めた仕様。毎日の改良でも変えない）

毎日の試用・改良（docs/daily）では、ここに書いたことは変えない。変えた方がよいと思ったときは、その日の報告に「提案」として書き、ユーザーの判断を待つ。

## 書類・印刷
- 作るのは**診断書と指示書（様式B）だけ**。申込書（様式A）を作る・印刷する機能は作らない（一度作って削除した）。
- 印刷の体裁は Excel版（`shindansho-excel/shindansho-shijisho.xlsx`）の「診断書」「指示書」シートに合わせる。注意事項まで含めて各1枚。A4・US Letter のどちらでも1枚に収める。
- 署名欄は「医務官氏名／健康管理医　＿＿＿　印」、その下に「（署名押印）」。
- 指示書には病名を書かない。フリガナはカタカナで印刷。
- 公館名は在外公館リストの書き方（例：在タイ大使館）で印刷。

## 入力
- 処方は電子カルテのオーダーの形：薬品・規格・剤形・用法・1回量・日数（**薬ごと**）。用法は一覧から選ぶか直接入力、回数は「分1・分2・分3」の書き方（「2X」の X は使わない）。
- **不均等**（朝・昼・夕・寝る前ごとの量）、**頓服・週1回などは回数**、**用量の自由記載**と**補足（自由記載）**ができる。
- **後発医薬品への変更不可は薬ごと**。
- 病名は最初1行、Enterで次の行。
- 療養者が家族のときは「館員本人の氏名」を入力できる（申込書に書くための控え。**印刷物には載せない**）。
- 小児のための**体重（kg）**を入力できる（印刷しない）。体重があれば、一部の薬は小児の体重あたりの1日量の目安（参考値）で照合して「要確認」を出す（2026-11-07）。
- 「設定」に**兼轄・巡回で担当する公館**を登録でき、その公館の患者には「所属が異なります」の注意を出さない（2026-11-07）。
- 「別の人を登録」では医師・発行日だけ引き継ぎ、患者の情報（職員コード・所属公館を含む）・病名・処方は空にする。
- 所属公館 ⇄ 公館コードは自動入力（在外公館リストは公開してよいとユーザーが判断済み）。
- 「購送対象外の薬」欄は作らない（削除済み）。

## 薬
- **向精神薬はオーダーできる**が、入力時・チェック・印刷時に「購送には本省の許可が必要」と必ず注意を出す。エスゾピクロンは向精神薬ではない。
- 向精神薬は、処方欄の常時の注意書きや入力候補・分類名で**明示しない**。オーダーに入れたときだけ、その薬の欄の下に「購送には本省の許可が必要」と注意を出す（2026-11-05、ユーザーの判断）。
- 診断書・指示書の注意書き「向精神薬・睡眠薬は３０日、新薬は１４日の処方日数制限がある。」から向精神薬・睡眠薬の部分を外し、「新薬は１４日の処方日数制限がある。」とする（アプリ・Excel版とも。2026-11-05、ユーザーの判断「向精神薬の注意書きは不要」）。
- 「作成／保存一覧／設定」のタブは、スクロールしても画面の上に固定する。右のチェック結果の欄も画面の高さいっぱいで固定する。
- **麻薬・覚醒剤原料・大麻など**は処方欄に入力できない。
- カプセルは購送できる剤形。
- 薬剤マスタは参考値（添付文書との照合はしていない）。

## 画面・運用
- アプリを開くたびに免責事項（病名と処方の組み合わせは医務官の責任で確認、療養費請求の可否を保証しない）を表示する。
- データはブラウザ内だけ（localStorage）。外部への通信は Content-Security-Policy で禁止。
- 保存は「上書き保存」と「別の書類として保存」を選べる。保存一覧は患者ごと。検索はひらがな・カタカナどちらでも。
- 移管・バックアップはパスワード付き（暗号化）にできる。画面ロック（PIN）は任意。
- ブラウザを使いたくない医務官は Excel版を使う。**Excel版はアプリと分離して `shindansho-excel/` で別に管理する**（2026-11-06、ユーザーの判断）。アプリの画面からExcel版へのリンクは置かない。アプリを直してもExcel版は自動では変えず、Excel版を直すのはユーザーが頼んだときだけ。
- **Excel版も仮の医師による使用テストを繰り返し、ブラッシュアップする**（2026-11-06、ユーザーの判断「ひたすら、エクセル版を仮の医者に使ってもらい、ブラッシュアップしたい」）。記録は `shindansho-excel/docs/daily/`。計算の誤り・文字の切れ・古い説明・分かりにくいメッセージなどは直してよい。様式（印刷する項目・注意事項の文言）や入力欄の作りを変えるものは提案にする。
- Excel版：**医務官氏名は空でもよい**（整合性チェックで知らせない。2026-11-07、ユーザーの判断）。不均等は服用薬の表の右の「朝・昼・夕・寝る前」の欄に数字で入れる（2026-11-07）。
- 返信の最後にアプリのURL（https://ysk713.github.io/-/shindansho/）を付ける。
