# 毎日の試用と改良の記録

毎朝、その日の「医務官」（専門・公館の状況・ITの慣れを日替わりで決めた架空の人物）になりきってアプリを試用し、見つかった問題を記録して、決定事項（../decisions.md）の範囲で直せるものは直す。

- 1日1ファイル：`YYYY-MM-DD_専門.md`
- 書くこと：今日の医務官の設定／試したこと／見つかった問題（重さ：高＝誤った書類・見逃し・データ消失・個人情報／中＝迷う・手戻り／低＝見た目）／直したこと（テストを付けて）／提案（仕様が変わるのでユーザーの判断が必要なもの）／良かった点
- 過去の記録と同じ指摘は繰り返さない。前に書いた問題が直っていれば「直った」と書く。
- 実在の氏名・実データは使わない。
