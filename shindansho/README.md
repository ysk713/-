# 診断書・指示書 作成支援（ブラウザ版）

https://ysk713.github.io/-/shindansho/ を開くだけで使えます。インストール不要です。

個人用医薬品購送で使う**診断書**と**指示書（様式B）**を入力フォームから作り、A4で印刷（PDF保存）します。

- 印刷結果は Excel版（[`excel/shindansho-shijisho.xlsx`](excel/shindansho-shijisho.xlsx)）の「診断書」「指示書」シートと同じ体裁で、注意事項まで含めてそれぞれA4 1枚です。指示書には病名を書きません。
- 用法の選択肢も Excel版の「用法用量マスタ」と同じです（「2X朝夕食後」の「2X」から1日分使用量を計算）。
- **ブラウザを使いたくない場合**は、画面右上の「Excel版」から空欄のExcelをダウンロードして使えます（入力シートに入れると診断書・指示書シートに反映されます）。

入力しながら、在外療養費書類レビューのチェック項目で不備をその場で表示します。

- 入力内容・保存した書類・設定は**このブラウザ（localStorage）にだけ**保存され、外部には送信しません。
- **バックアップ**：画面右上の「バックアップ」で、保存データをJSONファイルとしてPCにダウンロードできます。Chrome・Edgeでは「設定」で保存先フォルダを一度選ぶと、「保存」のたびにそのフォルダへ自動で書き出します（`shindansho-backup-日付.json`、同じ日は上書き）。7日以上バックアップしていないと作成画面にお知らせが出ます。
- 元に戻すとき・別のPCで使うときは「設定」→「読み込み」でバックアップファイルを選びます。
- 試しに使うときは「設定」→「サンプルを入力」（架空の療養者）。
- 「保存一覧」は患者ごと（氏名・生年月日・職員コードが同じ人）にまとまり、発行日の新しい順に並びます。氏名・フリガナ・職員コード・公館で絞り込めます。
- **患者の異動（移管）**：「保存一覧」の患者ごとの「移管用に書き出す」で、その患者（同じ職員コードの家族も選べます）の書類を**パスワード付きのファイル**に書き出せます。メールに添付して異動先の医務官に送り、異動先では「移管データを読み込む」で読み込みます。暗号化はブラウザ内で行い（PBKDF2-SHA256 で鍵を作り AES-GCM 256bit）、ファイルの外側に個人情報は残りません。**パスワードはファイルとは別の手段（電話・別のメールなど）で伝えてください。**
- 保存済みの書類を開いているときは「上書き保存」か「別の書類として保存」（元の書類は残す）を選べます。
- 「別の人を登録」で、職員コード・所属公館・医師・発行日を引き継いだまま、別の人（家族など）の書類を作れます。
- 「保存一覧」→「前回から作成」で、同じ処方の書類を今日の発行日で作り直せます。

## 入力時のチェック

| 区分 | 内容 |
|---|---|
| エラー相当 | 必須項目の未入力、承認上の1日上限超過、新薬の14日制限超過、マスタにない規格、購送できない薬（向精神薬など）が処方欄にある |
| 要確認 | 28日周期製剤の日数、病名に保険適応の病名がない、兼轄（療養者と発行医の所属が異なる）、同成分の重複、職員コードの桁数 |
| 要確認（軽微） | 自筆署名＋押印が必要な発行日、調節可で数量が確定しない、90日超、後発品変更不可なのに一般名、公館名の表記揺れ |

数量は「1日使用量 × 日数」を切り上げて自動計算します（調節可のときは上限側）。

## 購送できない薬

- **向精神薬・麻薬・覚醒剤原料など法律で規制されている薬**は処方欄で選べません。名前を入力しても受け付けず、印刷もできません（判定リストは `drugs.js` の `BANNED_DRUGS`）。
- 処方欄の剤形は購送できるもの（錠・OD錠・カプセル・散・顆粒・貼付剤）だけです。
- 軟膏・液剤・坐剤・ガス使用吸入薬・予防薬など購送できない薬は、「購送対象外の薬（自由記載）」欄に書きます。この欄は診断書にだけ印刷され、指示書には載りません。

## 薬剤マスタ

`drugs.js` に、外来で継続処方されることの多い標準的な内服薬 202品目（降圧薬・糖尿病・脂質・消化器・鎮痛・アレルギー・精神・睡眠・泌尿器・婦人科・漢方など23分類）を、規格・1日上限・投薬期間制限・適応病名つきで入れています。**参考値**なので、最終確認は最新の添付文書・薬剤部の回答で行ってください。
「設定」→「薬剤マスタの追加・上書き」で、新薬（14日制限）などをブラウザごとに追加できます。

## 免責事項

本アプリ（Excel版を含む）は診断書・指示書の作成を補助するものです。チェック結果や薬剤マスタは参考情報であり、**病名と処方の組み合わせ（保険適応・用量・日数など）は医務官ご自身の責任で確認してください**。**療養費請求の可否や、その責任を保証するものではありません。**

## 注意

- 印刷レイアウトは汎用の書式です。正式な様式に合わせる必要がある場合は `app.js` の `shindanHtml` / `shijiHtml` を調整してください。
- 署名・押印は印刷後に手書きで行います。
- 所属公館を入れると公館コードが、公館コードを入れると公館名が自動で入ります。一覧は `posts.js`（個人用医薬品購送申込書 R7.7.3版の「在外公館リスト」、261公館）です。
