# 医務官月報 取りまとめ（ブラウザ版）

https://ysk713.github.io/-/geppou/ を開くだけで使えます。インストール不要です。

- 取り込みは ①対象月を選ぶ → ②月報ファイルを追加 → ③「読み取り開始」の順。月を選ぶまでファイルは受け付けません。
- 対応形式: PDF（ZIP形式のPDF／通常のPDF）と Word（.docx）。古い .doc は .docx で保存し直してください。
- 世界地図の「丙表から読み取った流行中の病気」で、各公館の報告事項の文章から病名（デング熱・コレラ・エボラ等）を拾い、「流行・増加／減少・終息／言及のみ」に分けて地図と表に出します。
- 表記の違う病名は1つにまとめて集計・表示します（例: 感冒・急性鼻咽頭炎・上気道炎 → かぜ（急性上気道炎）、古典デング・デング出血熱 → デング熱）。まとめ方は「設定」→「病名のまとめ方」で付け替えられます。
- 世界地図の「病名で見る」で、個別の病名（例: デング熱）ごとに乙表の件数を国別に塗り分け、丙表で触れている公館に印を付けます。
- 読み取り・集計・地図・Word作成はすべて**ブラウザの中だけ**で行い、PDFや集計結果は外部に送信されません。
- データはそのブラウザ（IndexedDB）に保存されます。別のPC・ブラウザでは見えないので、「設定」→「書き出し」でバックアップしてください。
- 試しに使うときは「設定」→「サンプルデータを読み込む」（架空の15公館×3か月分）。

画面: 取り込み／ダッシュボード／世界地図（疾病の流行・受診者数・感染症や災害・巡回健診・医務官の異動）／5行サマリー／巡回健診／医務官の異動／推移／Wordレポート／設定

公館マスタと疾病分類ルールは `data.js`（`geppou-app/geppou/posts.py`, `icd.py` と同じ内容）。
`lib/` は同梱ライブラリ（JSZip, pdf.js, SheetJS, Plotly, docx）で、外部CDNには接続しません。
Python版（手元PCで動かすStreamlitアプリ）は `../geppou-app/` にあります。
