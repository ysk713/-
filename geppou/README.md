# 医務官月報 取りまとめ（ブラウザ版）

**目的**：各公館から届く医務官月報を取りまとめ、世界の疾病・受診の動向を疫学的に俯瞰すること。そして、月報の提出率を上げ、内容を充実させること。

**最終的な目的**：月報データの蓄積を医学への貢献につなげ、館員の健康管理を通じて、日本外交および国益に貢献すること。

https://ysk713.github.io/-/geppou/ をブラウザで開くだけで使えます。PCに別のソフトを入れる必要はありません。

- **医務官配置表**は Excel のほか **PDF・Word** も読めます。「医務官配置表」の欄にドラッグ＆ドロップ（または「配置表を選ぶ」）。月報の欄に一緒に入れても、ファイル名に「配置」があるか、中身が配置表（「配置表」の見出しと「在◯◯大使館」が並ぶ）なら配置表として振り分けます。公館の欄は「ケニア」のような**国名＝大使館**、「広州総」「上海 総」「香港（総）」「総瀋陽」のような**「総」付き＝総領事館**として読みます（「在◯◯日本国大使館」の正式名も可。Excel の配置表も同じ）。PDF は1行ごとに公館名・医務官名（漢字）・ふりがな・備考（退避・欠員など）を読み取るので、保存の前に「中身を見る」で確認してください（文字のないスキャンPDFは読めません）。
- 取り込みは ①対象月の決め方を選ぶ → ②ファイルまたはフォルダを追加 → ③「読み取り開始」の順。
- 読み取り中に他のタブ（ダッシュボード・地図など）を開いても、読み取りは止まりません（「取り込み」タブに ⏳ が出て、終わるとお知らせ。「取り込み」タブに戻ると確認の表が出ます）。読み取り中にページを閉じようとすると確認が出ます。
- 追加したファイルの一覧では、1件ずつ「読み取る」「消去」ができます。チェックを付けたものだけを「選択した ◯件を読み取る」でまとめて読み取ることもできます（選ばなかったファイルは一覧に残り、後から読み取れる）。読み取った結果は確認の表に足されます（同じファイルを読み直すと入れ替え）。
- 確認の表の「公館」は、**欄を押すと国名の一覧が開き**、文字を入れると絞り込めます（▲▼と Enter、または押して選ぶ。名前が入っている欄でも全部の候補が出る。英語名・都市名・「在◯◯日本国大使館」でもよく、入力し終えるとマスタの名前にそろう）。医務官のいない国も候補に出ます。巡回健診タブの実施公館・巡回先も同じです。
- 確認の表で職員・家族・その他の人数を手で入れる（直す）と、計は自動で計算されます（計を直接直すこともできます）。
- 確認の表でも、1行ずつ「保存」「消去」（表から消すだけで、保存済みのデータやファイルは消えない）、チェックを付けた行だけを「選択した ◯件を保存」できます。
- 読み取る前のファイルの一覧と、保存していない読み取り結果（確認の表で直した内容も）は、ページを再読み込みしたりブラウザを閉じたりしても残ります（このブラウザの中だけに控えます）。次に開くと取り込みタブに戻ります（「取り消し」で消えます）。
- 対象月は数字だけで入れられます：「202511」「2025011」「2025/11」「R7.11」などは、欄を離れると「2025年11月」になります。ファイル名の「2025011」（年4桁＋月3桁）も 2025年11月と読みます。
- 確認の表の「**要確認以外をすべて保存**」で、警告のない行だけを先に保存できます（要確認の行は表に残り、直してから「保存する」）。
- **同じ月・同じ公館の月報がすでに保存されている**とき（同じファイルをもう一度読み込んだときなど）は、保存の前に一覧を出し「スキップ（保存済みを残す）／上書きする／やめる」を選べます。同じファイルを一覧に重ねて追加することもありません。
  - 「ファイル名から自動で読み取る」（既定）：ケニア_202607.pdf、2026年7月_ケニア.docx、令和8年7月、R8.7、20260715 などから月を読み取る。ファイル名になければフォルダ名、それもなければ本文の「◯年◯月分」を使う。月の違うファイルをまとめて読み込める
  - 「手動で指定する」：選んだ年月にそろえて読み込む（本文の年月と違えば確認欄で知らせる）
  - 「フォルダを選ぶ」やフォルダのドラッグ＆ドロップで、サブフォルダも含めて中の月報をまとめて読み込める
  - 医務官配置表（名簿, .xlsx）も同じ場所に入れられ、適用月はファイル名（なければ表の見出しの「◯年◯月」）から自動で入る
- 対応形式: PDF（ZIP形式のPDF／通常のPDF）と Word（.docx）。古い .doc は .docx で保存し直してください。
- 世界地図の「丙表から読み取った流行中の病気」で、各公館の報告事項の文章から病名（デング熱・コレラ・エボラ等）を拾い、「流行・増加／減少・終息／言及のみ」に分けて地図と表に出します。
- 表記の違う病名は1つにまとめて集計・表示します（例: 感冒・急性鼻咽頭炎・上気道炎 → かぜ（急性上気道炎）、古典デング・デング出血熱 → デング熱）。まとめ方は「設定」→「病名のまとめ方」で付け替えられます。
- 世界地図の「病名で見る」で、個別の病名（例: デング熱）ごとに乙表の件数を国別に塗り分け、丙表で触れている公館に印を付けます。
- 読み取り・集計・地図・PDFレポート作成はすべて**ブラウザの中だけ**で行い、PDFや集計結果は外部に送信されません。
- データはそのブラウザ（IndexedDB）に保存されます。タブやブラウザを閉じても残りますが、「Cookie とその他のサイトデータ」の削除やシークレットウィンドウでは消えます。別のPC・ブラウザでは見えないので、「設定」→「書き出し」でバックアップしてください（バックアップファイル `.geppou` はPDFと同じパスワードで暗号化され、このアプリでしか読み込めません。以前の `.json` も読み込めます）。まだ書き出していないときや、最後の書き出しから7日以上たって変更があるときは、画面上部に声かけを表示します。
- **パスワード付きの月報PDF**は、共通のパスワードで自動的に開いて読み込みます（画面にはパスワードを表示しません）（別のパスワードのときは入力を求め、入力したパスワードは同じ取り込みの続くファイルにも使います）。
- **公館カード**（国歌を聞く・月報の全文などのカード）は、見出しの行（⠿ 公館カード）をドラッグして画面上の好きな位置へ動かせます。位置は覚えておき、次に開いたときも同じ場所に出ます（画面からはみ出さない）。右下・左下の隅のつまみをドラッグすると大きさを変えられ、大きさも覚えます。見出しをダブルクリックすると右端・元の大きさに戻ります。
- 上のメニュー（タブ）は、画面を下へスクロールしても上に固定して表示します（ページを切り替えると、そのページの先頭から表示）。
- 上の**タブは横にドラッグして並べ替え**られます（ドラッグ中のタブは浮き上がって指についてきて、ほかのタブはアニメーションで場所をあける。タッチ画面は長押ししてから動かす、ふつうのスワイプはタブの横スクロール。キーボードは Alt+Shift+←/→）。並びはこのブラウザに保存され、「設定」の「タブの並びを元に戻す」で戻せます。設定ファイルの書き出し・読み込みにも含まれます。
- 試しに使うときは **https://ysk713.github.io/-/geppou/?demo** を開くか、「設定」→「デモを見る」。架空の112公館×12か月分（2025年9月〜2026年8月）を、保存済みの実データには触れずに表示します（デング熱・マラリア・インフルエンザの季節変動、髄膜炎・ラッサ熱・コレラ・エボラ出血熱・エムポックス・鳥インフルエンザ、熱波・台風・洪水、緊急移送17件・邦人対応30件、巡回健診、医務官の異動、未提出公館などの筋書き入り）。甲表は休暇期の減少や公館の性格（家族帯同・旅行者の多さ）で内訳が変わり、乙表は1公館あたり約20病名（生活習慣病・こころの不調・子どもの感染症・花粉症・大気汚染・高山病・寒冷地のけが・旅行者下痢症・狂犬病曝露後予防・定期健診・季節性ワクチンなど）、丙表は感染症・個別の出来事・医療機関と薬剤・健康管理（健診・ストレスチェック・健康講話・電話相談）・生活環境（PM2.5・寒波・砂嵐・停電・高地）を書いています。デモ用データは `geppou-app/sample/make_demo.py` で作り直せます。

地図は**平面**が標準で、「🌐 地球儀」を選ぶと地球儀になります。地図には**国名・首都（★）・人口50万人以上の都市（●）**を表示します（地図の上の「国名・首都・都市」で消せる）。地球全体を見ているときは大きな国の名前・人口500万人以上の首都の名前・人口100万人以上の首都の★・人口300万人以上の都市の●だけにし、地球儀を約1.8倍以上に拡大すると、すべての国名・首都と50万人以上の都市の●・100万人以上の都市名が、約4.5倍以上でさらに50万〜100万人の都市名も出ます。色を塗った国の上の名前は白、塗っていない国の上は濃い色。国・首都・都市・公館の印に**マウスを載せると指の形**になり（クリックできる所の目印。マウスを載せただけではカードは開かない）、**クリックするとカードが開きます**（✕ で閉じるか、海や何もない所にマウスを置くと〔約0.5秒〕閉じる。カードの上にマウスがあるとき・ツアー中は閉じない）。国は公館カード（公館のない国は国のカード）。どのカードにも「🎵 国歌を聞く」があり（首都・都市はその国の国歌）、首都・都市は人口と **Wikipedia（日本語版）へのリンク**のカードです（アプリが自動で Wikipedia に接続することはなく、リンクを押したときだけ開く）。カード（公館のある国は公館カード。公館カードにも国〔総領事館は都市も〕の Wikipedia へのリンク。インターネットが必要）。国名・都市のデータは Natural Earth（パブリックドメイン。`lib/places.json`、`geppou-app/sample/build_places.py` で作成）。地球儀では、**アジア・ヨーロッパ・アフリカ・北アメリカ・南アメリカ・オセアニア（六大州）**のボタンで、その地域まで地球儀がくるっと回るアニメーションで向きを変えられます（中東はアジアに含み、アジアは中東から日本まで見える向き）。どちらも地図の枠そのものは動きません：平面はドラッグで東西に回す（太平洋中心などにできる）だけ、地球儀はドラッグで回転・ホイールで拡大です（ハイライト・ツアー中だけ自動で地球儀にし、終わると平面に戻ります）。陸地・国境の下地データ（`lib/topojson/`）も同梱しているので外部には接続しません。PDFレポートの地図は平面です。

世界地図の仕掛け:
- ✨ 今月のハイライト・ツアー（別タブ） … 押すと別のタブが開き、地図を大きく表示してツアーを行う（音を出すため、そのタブで「▶ ハイライト・ツアーを始める」を押す。元のタブはそのまま使える）。東京（成田）を出て、アジア・大洋州 → 中東 → アフリカ → ヨーロッパ → 米州と世界をひと回りし（飛行機の区間は「✈ 成田国際空港（NRT）→ スカルノ・ハッタ国際空港（CGK）」のように出発・到着の空港名を吹き出しと地図上に表示。空港は各国の玄関口の空港〔`lib/airports.json`、OurAirports のデータでパブリックドメイン、世界医療情報マップと共通〕、総領事館や首都と玄関口が離れている国は公館のある都市の空港）、地域ごとに話題の多い公館（流行・増加の報告、新着アラート、災害・治安、緊急移送、巡回健診）に最大4つずつ立ち寄る（話題のない地域は受診者数の多い公館を紹介）。流行・増加の報告や新着アラートのある公館へ地球儀が順に回り、丙表の一文を吹き出しで紹介。東京を出発し、飛行機が航路を描きながら次の公館へ飛ぶ。移動手段は道のりで変わる：2,500km以内なら、大圏上を細かく区切って陸か海かを同梱の国境データで調べ、**陸は🚗車（エンジン音とクラクション）、海は🚢船（汽笛と波の音）に途中で乗り換える**（船が陸の上を走らない。40km未満の小島・湖・海岸線の誤差は前後に合わせる）。線も区間ごとに道（茶）・航路（青の点線）で描く。**高速鉄道が実際に走っている区間は🚄高速鉄道**（京滬高速鉄道 北京〜上海、京哈高速鉄道 北京〜瀋陽、上海〜広州、広深港高速鉄道 広州〜香港、上海〜香港・瀋陽、アセラ ワシントン〜ニューヨーク、ユーロスター ロンドン〜パリ、ICE パリ〜ベルリン。青い実線、レールの継ぎ目の音）。陸路（車）の移動は乗り物をときどき変える：**近くの国（約1,000km以内）へは🚁ヘリコプター（約35%）・🚑救急車（約20%）**、遠い陸路は🚑救急車（約30%）。救急車はピーポーのサイレン・赤い点線。**60〜600kmで海を渡る（島・海峡。例：ドバイ→カタール、英国→フランス、ジブチ→イエメン）か乗り換えが多すぎるときは🚁ヘリコプター**（ローターの音。緑の点線）。遠い所、乗り換えが多すぎる島づたい、1,500kmを超える陸路は✈飛行機（ジェット音）。**着いたらその国の国歌**の旋律が流れる（「🔊 音あり／🔇 音なし」で切り替え）。国歌は旋律を確実に確認できたもの（日本「君が代」・米国「星条旗」・英国「国王陛下万歳」・フランス「ラ・マルセイエーズ」、いずれもパブリックドメイン）だけで、それ以外の国は地域の音楽を流す。音はすべて録音を使わず `music.js` がブラウザ内で演奏する（地域ごとの音階・楽器の音色・リズムで国ごとに旋律を作る。中国「茉莉花」、ドイツ「歓喜の歌」、ロシア「コロブチカ」、メキシコ「ラ・クカラチャ」などはパブリックドメインの旋律）
- 音はフェードイン・フェードアウトで重ねて切り替える（出発するときは国歌・音楽が約2秒でフェードアウトしながら乗り物の音がフェードイン、着いたら乗り物の音が約1.5秒鳴り続けてフェードアウトしながら国歌がフェードイン）
- ツアーの出発は**霞が関の外務省**。🚄京成スカイライナーで**成田国際空港**へ向かうところから始まり（音楽は流さず効果音だけ）、成田から✈政府専用機で最初の公館へ
- ツアーの最後は、最後の公館から✈**政府専用機**で**成田国際空港**に帰国し（着いた時点で「君が代」）、🚄京成スカイライナーで**霞が関の外務省**に戻って終わる（自動では先へ進まず、「▶ もう一周」で最初の公館からもう一度回る）。日本を出るとき（東京→最初の公館）と日本に帰るときだけ政府専用機（白い機体・白い航路、赤い縁取り）で、それ以外の空路はふつうの飛行機
- ツアーは、**移動中は遠目に**引いて（遠い所ほど引く：6,000km超は地球全体、2,500km超 約1.3倍、600km超 約1.8倍、それ以内 約2.4倍）、**着く直前から寄って、どの国も大きく拡大**して見せる（約3.6倍）。国歌が流れている間は、画面の大きさの変更などの再描画で拡大が戻らないよう約3.6倍を保つ（ドラッグやホイールで自分で動かしたときはその操作を優先）。拡大しても地球儀が左右で切れないよう、ツアー中は地図の表示範囲を地図全体に広げる
- ツアー中も地球儀をつかんで（ドラッグで）回せる。移動中につかむと、その区間はカメラが乗り物を追いかけるのをやめ、回した向きのまま乗り物と線を描き続ける（ツアーは止まらず、次の国からまた自動で追いかける）
- ツアー中は、着いた国の**公館カード**を画面の右に自動で開く（ツアーは止めない）。「🗂 カードを隠す」か カードの ✕ で閉じると次の国からも出さない。「🗂 公館カード」でまた出す。ツアー中に地図の国・都市などをクリックすると、そのカードを出し（ツアーは止めない）、次の国に着いたらその国のカードに替わる。自分で選んだカードは、海や何もない所にマウスを移すと（約0.5秒）、国歌が流れている国のカードに戻る（カードの上にマウスを移したときは戻さない）。何もない所（海など）をクリックすると一時停止
- 移動中に「次へ」「前へ」を押すと、前の国に戻らず、乗り物のいまの位置からそのまま次の国へ向かう（続けて押せば次々に進む）
- ツアー中に地図（地球儀）を**クリックすると一時停止**する（ドラッグして回したときは止まらない）。乗り物の移動・音楽・国歌・次の国へ進むまでの待ち時間がその場で止まり、地図の上の「▶ 再開」か吹き出しの「▶ 再開」で続きから動く。吹き出しの「⏸ 一時停止」でも止められる
- **世界ツアーは、ブラウザの別のタブに移っても止まらずに動き続けます**（音も流れ続け、別のタブにいる間は**音量を半分くらい**に下げる。戻ると元の音量）。ツアーのタブを閉じたり、アプリの別のページに移ったりしたときは、どこまで進んだかを覚えておき（7日間）、次に開いたとき「▶ 続きから再開」か「最初から始める」を選べる
- 地図の巡回健診・医務官の異動・緊急移送の線にマウスを載せると、線の途中でも吹き出しで「🩺 巡回健診」「👤 医務官の異動」「🚑 緊急移送」の区別と、出発・到着の公館（異動は医務官名と月、巡回健診は期間）を表示
- ▶ タイムラプス … 月を古い順に自動で送り、塗り分けと流行の印の移り変わりを再生
- 新着アラート … 前月になかった病気（丙表）や急増した病気（乙表）の公館が点滅。ダッシュボードにも一覧
- 飛行機アニメ … 巡回健診・異動の線の上を ✈ が飛ぶ
- 公館カード … 国・印・表の公館名をクリックすると、医務官・受診者数の推移・10行サマリー・病名・巡回健診をまとめたカードが開く

緊急移送・邦人対応:
- 「緊急移送」タブ … 丙表の「緊急移送」「搬送」の記述から、公館・対象・病名・移送先・手段・転帰を拾って一覧と地図（移送経路）に出す
- 「邦人対応」タブ … 丙表で邦人（旅行者・出張者・留学生・在留邦人）に触れた記述を、病気・事故・事件・死亡に分けて一覧と地図に出す
- **数えすぎない工夫**：邦人対応は、邦人・出張者・留学生の**実際の事例の文**（入院・死亡・事故・事件・面会・相談への対応など）だけを数えます。「邦人保護 なし」「被害は報告されていない」「邦人が利用する病院」「出張者向けに情報提供」のような文は数えません。緊急移送は「緊急移送」などの言葉があるか、**移送した先の国（日本を含む）**が書かれた文だけ（「該当事例なし」「移送が必要な場合は」「救急車で市内の病院へ搬送」は除く）。続けて書かれた同じ事例の文や、行き先と病名が同じ移送は1件にまとめます。巡回健診は実際の巡回の文だけ（「巡回する医師がいる」のような一般の話は除く）で、同じ巡回先を何度も書いていても1件。医務官の交代は、名字だけの記載（「大湾」と「大湾 喜行」）を同じ人とみなします。
- **全体概況は要点だけ**：丙表で流行・増加が報告された病気は、報告した公館の多い順に主な8つ（公館名は4つまで、残りは「ほか◯公館」「ほか◯件」）。新着アラートは主な5件（上の流行・増加と同じものは重ねない）、気象・災害と治安・社会は主な6つ、緊急移送は8件、巡回健診は10件まで。全部は各章と公館別サマリーにあります。
- どちらも表で直して保存でき、全期間の月別グラフも出る。PDFレポートにも章を追加

公館カードには国旗（flag-icons, MIT）を表示します。

統計タブ:
- 1公館あたり受診者数の記述統計（公館数・合計・平均・標準偏差・最小・四分位・中央値・最大・変動係数、地域別）と受診者の構成比
- ドーナツグラフ（受診者の内訳・地域別構成・疾病分類の構成・実患と検診/予防接種）
- 地域別の箱ひげ図（公館ごとのばらつき・外れ値）、前月比の増減ランキング、病名上位15と割合
- 病名×月・地域×月のヒートマップ（季節による流行の波）
- 地域の色は色覚多様性に配慮した検証済みパレットで固定し、どのグラフでも同じ地域は同じ色

画面: 取り込み／ダッシュボード／世界地図（疾病の流行・受診者数・感染症や災害・巡回健診・医務官の異動）／10行サマリー／巡回健診／医務官の異動／推移／PDFレポート／AI分析（匿名）／設定

## 書き出し（PDFのみ）

- 「PDFを作成（別のタブで開く）」を押すと新しいタブでPDFを作成し、できあがったPDFをそのタブで表示します（表示・印刷・保存はそのタブで。作成中も元のタブで作業を続けられます。新しいタブが開けないときは元のタブで作成してダウンロード）。
- レポートの書き出しは **パスワード付きPDF** のみです（Word出力は廃止）。暗号化は PDF 2.0 標準の AES-256。開くにはパスワードが必要です（同じパスワードで解除もできます）。パスワードは所内で共有しているものを使ってください。
- **ファイル名は自動で付けます**（例：`医務官月報統合レポート_202609.pdf`、期間・地域があれば `_12か月_アフリカ` などを添える）。「💾 保存」では、そのファイル名を入れた保存の画面が出て、保存する場所（医務官のみがアクセスできるフォルダ）も選べます。作成したタブのビューアの保存ボタンや「PDFだけを全画面で開く」から保存しても同じファイル名になります（アプリのオフライン用の仕組み〔サービスワーカー〕でPDFをファイル名の入ったアドレスで表示するため。PDFはこのブラウザの中だけに置き、外部には送りません。タブを閉じると消します）。
- PDFレポートは **10MB 未満**に収めます。ページ数が多いとき（全期間・36か月など）は、上限を超えないよう、一部のページの画像の画質・解像度を自動で少し下げます（文字が読める範囲。表紙・目次など先頭のページから順に、そのページの持ち分に収まる最もきれいな画質を選ぶ）。できあがりの大きさは作成後に MB で表示します。
- **PDFにする項目を選べます**（全体概況・世界地図〔疾病分布：国ごとの最多疾病分類の塗り分けのみ〕・受診者数統計・疾病分類統計・巡回健診と異動・緊急移送と邦人対応〔報告のあるものだけ。どちらもない月は章ごと載せない〕・公館別10行サマリー。表紙と目次は常に入る。章番号は選んだ順に振り直す）。
- **目次の各行を押すとその章へ移動**します。ビューアの「しおり」からも移動できます。
- **「取扱注意」は印刷したときだけ出ます**（斜めの透かし・右上の印・下の注意書き）。PDF の任意コンテンツ（画面では非表示・印刷時は表示）で重ねています。Chrome・Edge（PDFium）や Acrobat は対応。対応していないビューアでは画面にも表示されたままになる（＝印刷には必ず出る）ようにしてあります。
- **パスワードは同じパスワードで解除できます**：所有者パスワード（解除・権限の変更に使う）を、開くときと同じパスワードにしています。Acrobat などの「セキュリティを削除」で同じパスワードを入れると、パスワードなしのPDFにできます。
- アプリの画面をブラウザから印刷した場合も、全ページに「取扱注意」の透かしが入ります。
- 注意：パスワードはアプリのソースコードに書かれています（公開ページなので、コードを読めば分かります）。PDFの誤送信・紛失への備えとしては有効ですが、厳密な秘密管理が必要な場合は運用で補ってください。

### 分析の目的から選ぶ・医務官あての月次サマリー

- PDFレポートのタブの「**どんな分析をしたいか**」で目的を選ぶと、それに要る章と統計に**自動でチェック**が入ります（いくつ選んでもよく、下の項目で足し引きもできる。目的を外すと、残りの目的の分だけになる）。
  - 📋 幹部への定期報告（要点）…全体概況・地図・受診者数・疾病分類・緊急移送と邦人対応・公館別5行サマリー
  - 📈 時系列の傾向を知る…月ごとの傾向・前年同月・いつもより多い病名・感染症の推移・病名×月・増えた減った公館（**期間が1年より短ければ直近12か月にする**）
  - 🦠 感染症の流行を監視する…地図・いつもより多い病名・感染症の推移・病名×月・前年同月
  - 🌏 地域を比べる…地図・地域別の受診者数と疾病分類・ばらつき・構成比・疾病分類×地域
  - 🏥 業務量・体制を見る（配置の検討）…公館別の受診者数（医務官1人あたり）・ばらつき・増えた減った公館・巡回健診と異動・提出状況
  - 🚑 邦人保護・緊急対応／📮 月報の提出・記載状況／📊 統計を詳しく／🤖 AI分析の結果をまとめる
- 新しい章「**月報の提出・記載状況**」：1か月は提出率と未提出の公館（退避・空席の別）、期間は月ごとの提出率のグラフと未提出の多い公館。あわせて記載状況（甲表の数値がない・乙表が空・丙表が50字未満の月報）。

### PDFレポートの形式（期間・地域）

「PDFレポート」タブで **期間**（直近1か月／直近3か月／直近6か月〔半年〕／直近12か月〔1年〕／直近36か月〔3年〕／**直近60か月〔5年〕**／**全期間**〔月報のある最初の月から最新の月まで。前の期間との比較はしない〕。「直近」は上で選んでいる月ではなく、**月報のある最新の月**を終わりとしてさかのぼる。**📅 期間を指定**で始めと終わりの月を自由に選べる〔「202601」のように数字だけでも入れられる〕）と **地域**（全世界、またはアフリカ・アジア・大洋州・ヨーロッパ・中東・北米・中南米を複数選択）・**国**（国名を入力して追加。英語名でもよい。地域と組み合わせられる。「全世界」を押すと地域・国の選択をすべて外す）を選んで作れます。

- **1か月**：これまでどおりの月のレポート（地域を選ぶと、その地域の公館だけで作る。表紙に対象地域）
- **3・6・12・36・60か月・全期間**：期間のまとめのレポート（1年を超える期間では、全体概況の受診者数を**年ごとにまとめ**〔年ごとの延べ・月平均・提出公館数〕、流行・増加の報告のあった月は月数と最初・最後の月で示し、表の月には年を付ける）。全体概況（期間の受診者数の合計・月平均・前の同じ長さの期間との比較、月ごとの提出公館数と受診者数、多い疾病分類・病名、丙表で流行・増加が報告された感染症と公館・月、緊急移送・邦人対応・巡回健診・医務官交代の件数）、世界地図（期間の疾病分布）、受診者数（月ごとの推移、内訳、公館別の期間合計・提出月数・月平均・前の期間比）、疾病分類（月ごとの推移、分類別・地域別の件数、診断名トップ10）、巡回健診・異動・緊急移送・邦人対応（月の欄つき）、公館別の状況（期間の受診者数と月ごとの値、主な疾病、丙表の感染症と月、最後の月の医療事情）
- ファイル名は「医務官月報統合レポート_202608_6か月_アフリカ.pdf」のようになります。
- **統計分析**の章：入れる統計をチェックで選べます（記述統計／受診者数のばらつき〔箱ひげ図〕／構成比〔受診者区分・疾病分類の地域別の割合〕／疾病分類×地域〔ヒートマップ〕／病名の上位×月〔ヒートマップ。1か月のときは×地域〕／月ごとの傾向〔1公館あたりの値の回帰。期間が短いときは直近12か月〕／**いつもより多い病名**〔期間の件数を、前の年の同じ月（なければ直前の12か月）の1公館1か月あたりの件数から見込んだ数と比べ、5件以上で1.3倍以上の病名を倍率の棒グラフで。2倍以上は赤、基準の時期にほとんどなかったものは「新たに報告」〕／**主な感染症の月ごとの推移**〔感染症及び寄生虫症の病名の上位6。期間が短いときは直近12か月〕／**前年同月との比較**〔1〜12月の線を年ごとに重ね、受診者数と感染症の件数〔1公館あたり〕の季節の波と前年との違いを見る。同じ月が2年分そろうと表示〕／**公館別の受診者数**〔1か月あたりの受診者数の多い公館の上位25。職員・家族・その他の内訳と全公館の中央値の線。業務量の偏りの目安。**医務官1人あたり**で比べ、身体とメンタルの2人体制の公館〔フランス・タイ。アメリカ・南アフリカはメンタル空席のため1人、サンパウロはメンタルの医務官1人〕は受診者数を人数で割る。配置表に身体とメンタルの欄があるときは、名前の入っている人数〔空席は数えない〕を使う〕／前月・前の期間と比べて増えた・減った公館）。ヒートマップは少ないほど青・多いほど赤。「血症」「症」「炎」など、病名の後ろ半分だけの切れ端は病名として扱いません（乙表の病名の欄が2行に折り返して件数の数字がはさまったときは、前の語とつないで「高尿酸血症」のように読み取ります。以前に保存した月報の切れ端も載せません）。乙表の病名の欄が折り返して、分類の見出しやICDコードに前半がくっついたとき（「内分泌，栄養及び代謝疾患高尿酸／血症(9)」「E79高尿酸 血症」）も、つないで「高尿酸血症」と読み取ります。以前に自動で作ったサマリーも作り直し、「血症」を載せません。**ICD-10の分類名に対応**：乙表の病名はICD-10の分類名（「その他の家具からの転落」「既知の胎位異常又はその疑いのための母体ケア」「その他の成人の人格及び行動の障害」など）で書かれることが多いので、その言い回しで大分類を決めるキーワードを大きく増やしました（転落・衝突・接触・曝露・毒作用・既往歴・家族歴・胎盤・母体ケア・人格・錐体外路・硝子体 など）。ふりがな書き（「そう<掻>痒症」「う<齲>蝕」「乾せん<癬>」）は漢字の形でも照合します。脳梗塞・脳出血・くも膜下出血はICD-10どおり循環器、先天奇形（Q）・周産期（P）は大分類の一覧にないので分類不能です。病名の前後に付いたごみ（表の罫線「|」、ICDコード「L00-」、「全集計用」「甲表は…延べ件数、乙」などの注記、分類の見出し「症状,徴候及び異常臨床所見・異」）は取り除き、「の皮膚炎」「に分類されないもの」のような途中から始まる切れ端は病名として数えません（以前に保存した月報も同じように直し、同じ病名になったものは件数を合わせます）。手で決めた分類・まとめ（設定の病名の分類・まとめ）は今までどおり優先します。結核・虫垂炎・心筋梗塞・胆石・胆のう炎・骨粗しょう症・白血病・風疹（ドイツ麻疹）・エムポックス（サル痘）などのまとめも加えました。病名のまとめで付けた名前が標準のまとめの言い換え（「感染性胃腸炎（疑い）」「胃腸炎（疑い）」→胃腸炎・下痢症、「単純ヘルペスウイルス感染症」→単純ヘルペス など）のときは、標準のまとめとして数えます（自分で付けた別の名前はそのまま）。統計タブで以前に保存した検定・推定の結果（PDFレポートの「検定・推定の結果」）からも、「血症」の行と記載を除きます。受診者数と実患件数の相関〔散布図〕はレポートからは外しました（統計タブの散布図・検定では引き続き使えます）。
- **AI分析の結果**の章：AI分析タブの「③ AIの回答を保存する」で保存した GaiXer／源内の回答を選んで入れられます（期間に入る月の回答は最初から選ばれる。見出し・箇条書き・表を読み分けて載せ、冒頭の取扱注意の文は載せない。「AIの回答のため、内容と数値は医務官が確認のうえ利用すること」と添える）。回答を保存するときも個人情報の点検をします。


## UpToDate へのリンク

ダッシュボードの診断名・新着アラート、地図の病名、ツアーの吹き出し、公館カード、統計タブの上位15のグラフなどで病名をクリックすると、UpToDate の検索結果が新しいタブで開きます（送られるのは病名だけで、公館名や件数は送りません）。**UpToDate はインターネットにつながっていないと開けません**（オフライン中にクリックするとお知らせが出ます）。主な病名は英語の検索語に置き換えて検索します。

## 使い方（チュートリアル）

画面上部の **「📘 使い方」** で、月報を取り込むまでの手順を図で順に説明します（はじめて使うときは自動で開きます）。

1. 組織内のポータルの「医務官用執務参考データ」のページで、【医務官月報】の「🔄 同期」を押す（最初に1回だけ）
2. エクスプローラで「医務官用執務参考データ - 医務官月報」→ 年度 → 地域のフォルダを開く
3. 月報くんの「取り込み」で「ファイル名から自動で読み取る」を選ぶ
4. 月報のファイル（またはフォルダごと）を、取り込みの点線の枠へドラッグ＆ドロップ
5. 「読み取り開始」→ 確認の表を見て「保存する」
6. 集計・PDFレポート・バックアップ

手順3〜6は「👀 この画面の場所を見る」で、月報くんの画面のその場所を光らせます（「📘 使い方に戻る」で続きへ）。図は画面写真ではなく要点を描いたもので、組織内のページのアドレス・サーバー名・パスワードは載せていません。

## PDFレポートに入れる統計・AI分析の選び方

PDFレポートのタブで「統計分析」の章を選ぶと、保存した検定・推定の結果の**最近10件**（新しい順）から選べます。**AIの回答は、章を選んでいなくても常に、保存したすべて**（新しい順）から選べます（選ぶと「AI分析の結果」の章にチェックが入ります）。

- 統計：統計タブの「検定・推定」で「📌 この結果を保存」したもの（チェックすると「保存した検定・推定の結果」の項目にも自動でチェックが入る）
- AI分析：AI分析タブの「③ AIの回答を保存する」で保存したもの
- レポートの期間に入る月のものは、はじめからチェックが入っています。

## PDFの作成を中止する

PDFレポートの作成中は **「■ 作成を中止」** が出ます（別のタブで作るときはそのタブに、このタブで作るときは「PDFを作成」の横に）。押すと、いま作っているページが終わったところで止まります。

## 動作の安定・速さ

- 起動時に、ブラウザへ「このサイトのデータを自動で消さない」ように頼みます（空き容量が少ないとブラウザが消すことがあるため）。結果と使用量は「設定」→「動作の記録・保存の状態」で見られます。

## 配置表の確認と医務官の異動

- 取り込みタブの「医務官配置表」の下に **保存した配置表** を月ごとに出します（新しい月から。公館数・配置あり・医務官の人数）。開くと中身（地域・公館・医務官・備考・配置）を見られ、要らない月は削除できます。表の枠は右下のつまみで縦に広げられます。
- 番号つきの配置表（PDF）で、**同じ欄に2人**（離任する人と着任する人。例：英国の行の下に番号のない行で新しい医務官）が書かれているときは、**発令年月日の新しい方をいまの医務官**、古い方を離任として読みます。表では「◯◯（離任）／◯◯（着任 2026/09/22）」と出ます。
- 「広」「メ」などの印だけで氏名のない欄は空席として読みます（印を氏名と取り違えない）。名が漢字の人のふりがなの一部を名と取り違えないようにしました。
- **医務官の異動**は、公館ごとに前に分かっている医務官（間の月の月報・配置表がなくてもよい）と比べ、新しい名前が出たときに交代とします。2人体制（身体・メンタル）で月報にどちらか1人だけが書かれていても交代にしません。配置表で空席になったときは「→（空席）」として出します。漢字が少し違っても（誤記・読み取りの違い）配置表の**ふりがなが同じなら同じ人**とみなします。前の公館も分かれば添えます（例：イラク→タイ）。

## 読み取りの一時停止・再開

読み取り中は「読み取り開始」の横に **「⏸ 一時停止」** が出ます。押すと、いま読んでいるファイルを読み終えたところで止まり（「⏸ 一時停止中…」）、**「▶ 再開」** で続きから読みます。ほかのタブを開いていても止まったままです。

読み取り中は **「■ 読み取りを中止」** も出ます。押すと、いま読んでいるファイルも含めてすぐに止まります。**読み終えた分は下の確認の表に出て、そのまま確認・保存できます**。まだ読んでいないファイルは「読み取る前のファイル」の一覧に残るので、あとで続きを読めます。

**時間がかかるファイルはスキップ**します：1件の読み取りが **60秒** を超えたら、そのファイルは飛ばして次のファイルへ進みます。飛ばしたファイルは一覧に **⏱ 時間がかかったためスキップ** の印を付けて残し（チェックは外れる）、1件ずつ「読み取る」を押すと **5分** まで待って読み直します。

## 大量の月報を読み込むとき

- 読み終えた分は**読み取りの途中でも約5秒ごと（と一時停止したとき）にブラウザ内に控えます**。途中でブラウザが落ちたり再読み込みしたりしても、読み終えた分は確認の表に、まだ読んでいないファイルは「読み取る前のファイル」の一覧に残ります。
- **1000件程度**のPDFを一度に入れても読み取れることを確かめています（テスト用の1000件で約15秒。スキャン画像のPDFは「要確認」になり、必要ならOCRで読み直す）。
- 「読み取る前のファイル」の一覧は **50件ずつ**表示します（「すべて選ぶ／外す」は全ページが対象）。
- フォルダを入れたとき、開けないファイルがあってもほかは読み込みます。OneDrive・SharePoint の同期フォルダでまだダウンロードされていないファイルは、右クリック →「このデバイス上に常に保持する」のあと入れ直してください。
- 取り込みタブの「📮 提出状況」と、設定の「登録済みデータ」の一覧は、**右下のつまみで縦に広げられます**（広げた高さは次に開いたときも使う）。提出状況は月が多くても公館名を1行で表示し、横に動かしても地域・公館の列は左に残ります。
- ブラウザへの保存は、月報を**月ごとに分けて、変わった月だけ**書き込みます（以前は保存のたびに全部を書き込んでいたため、月報が数千件あると1回の保存で画面が固まっていました）。保存後の提出状況の表も少しあとで作ります。大量の読み取り・保存の合間に画面へ制御を返すときは、タブが裏にあっても待たされない方法を使い（以前の方法は、別のタブを見ている間は1回ごとに1秒以上待たされ、保存がとても遅くなっていました）、タブが見えていないときは待たずに続けます。続けて保存したときは、待っている書き込みを1つにまとめます。
- 「保存する」「要確認以外をすべて保存」で大量に保存するときは、**40件ずつ少しずつ**処理して画面が固まらないようにし、表の上に「💾 保存しています… 1040 / 1206件」と進み具合を出します。保存中は表を触れず、ボタンをもう一度押しても二重には保存しません。
- 読み取った月報のうち、**同じ月・同じ公館の月報をすでに保存しているもの**には「保存済み（同じ）」「保存済み（内容が違う）」の印を付け、表の上に件数を出します（「同じ」＝受診者数・医務官・病名の数も同じ。印にマウスを載せると保存済みのファイル名と受診者数）。「保存済みだけ表示」で絞り込め、「保存済みと同じ◯件を表から外す」で同じものをまとめて外せます。表の中で同じ月・同じ公館が2つ以上あるときは「表の中で重複」。読み取りが終わったときの知らせにも件数を出します。保存するときは、今までどおり上書きかスキップかを聞きます。
- 確認の表は **30件ずつ**表示します（「◀ 前の30件」「次の30件 ▶」・件数の一覧で移動。「要確認だけ表示」で要確認の行だけに絞れる）。ページを移っても入力した修正・チェックは残ります。「保存する」「すべて選ぶ／外す」は全ページが対象です。数百件を一度に表に出すと、1文字入れるたびに表全体を計算し直して重くなるためです。
- 「デモを見る」ボタンの光る動きは、画面全体を描き直さない方法に変えました（大きな表を出しているときに画面が引っかかっていたため）。

## OCR（文字認識）で読み取る

- スキャンした月報や、文字が図形（アウトライン）になったPDFのように文字の情報がないものは、確認の表のその月報の下に **「🔎 OCRで読み取ってみる」** が出ます。押すと、文字のないページを画像にして文字を認識し、甲表（公館・医務官・受診者数）・乙表・丙表を読み直します。
- OCR はアプリに同梱した Tesseract.js（Apache-2.0）と日本語の学習データで、**ブラウザの中だけ**で動きます（外部には送りません。初回だけ準備に数秒）。1ページ数秒〜十数秒かかります。
- 誤読があり得るので、ページの画像と見比べて、数字・病名・医務官名を確かめてから保存してください（「OCRで読み取りました」と印が付きます）。
- うまく動かないときは「設定」→「🔎 OCRの動作確認」で、見本の文字を読ませて結果と時間（または原因のメッセージ）を確かめられます。
- 人数の欄（職員・家族・その他・計）は、全角の数字（１２）で入れても半角（12）に直ります。

## 足りない月報（提出状況）

- 「取り込み」タブの **📮 提出状況（足りない月報）** で、公館×月の表に ✓（提出）・**未**（足りない月報）を出します。期間は直近3・6・12か月／全期間。「足りない公館だけ表示」（最初はオン）と「足りない月報の一覧をコピー」（「2026年8月分（3公館）：…」の形。督促のメールなどに）があります。
- 対象は、医務官配置表にあるすべての公館（定員の公館。医務官がいない・空席・退避中の公館も含み、印を付ける）です。配置表が未登録ならアプリの公館一覧。番号つきの配置表PDF（「1 インド植山…」の形、結合したセルの公館名が行から外れるもの）も読み取り、表の見出しの「定員○公館○名」と読み取った公館数を見比べて出します。配置表の氏名の前の印（広＝広域担当、産＝産業医、メ＝メンタルヘルス相談医）は氏名に入れません（「広田」「広瀬」のような名字はそのまま）。メンタルヘルス相談医のいる公館（タイ・南アフリカ・アメリカ・サンパウロ・フランスの5館）のうち、身体の医務官とメンタルヘルス相談医（「メ」）の2人体制の公館は1公館として数え、配置表の中身に2人（空席を含む）を出します。公館の顔ぶれは、最新の配置表のものを過去の月にも当てはめます（医務官名は月ごとの配置表のまま）。月報を取り込み始めた月より前は数えません。
- 「設定」→「登録済みデータ」にも、月ごとの **未提出公館**（件数と公館名）を出します。
- 新しく入れたファイル・読み取った月報は、一覧や確認の表の **一番上** に出ます。

  - はじめにお読みください.txt

## オフラインで使う

- ネットにつながっているときは、開くたびに新しい版を確認して自動で入れ替えます（アプリ本体はネット優先、ライブラリ等は保存分を使用）。

- 開発者向け：`geppou/` のファイルを変えたら、公開前に `python3 geppou-app/sample/build_sw.py` を実行して `sw.js` を作り直してください（版の名前がファイル内容のハッシュになり、利用者のブラウザで自動更新されます）。

## 生成AIでの分析について（開いたときに注意書きを表示）

アプリを開くと「はじめにお読みください」を表示します（アプリの目的、仕組み、取扱いの注意）。処理も保存もブラウザ内だけで行い、インターネット経由で外部に送らない仕組みであることを説明し、閲覧履歴等を消去するとデータが消えるので必要な情報をエクスポートし、医務官のみがアクセスできるフォルダに保存することも記載。「上記の目的を理解し、個人情報の取扱いに細心の注意を払い、善意の利用者としてこのアプリを利用します」にチェックを入れるまでアプリを使えません（同じタブでの再読み込みでは出しません。「1か月間はこの注意書きを表示しない」にチェックすると、このPCのこのブラウザでは1か月間出しません。「設定」→「『はじめにお読みください』を表示」でいつでも表示し直せます）。生成AIで分析したい場合は、各自、必要な情報を個人情報を含まない形（個人が特定されない集計値など）にしたうえで、**MOFA GaiXer** または **政府AI源内** で行う運用とします。それ以外の外部AI・Webサービスに月報やアプリのデータを入力しないでください。

## AI分析（匿名）タブ

AIに貼る文章の冒頭には「【取扱注意】この集計は外務省AI（MOFA GaiXer）・政府AI源内専用です。」の表示と、AIへの「回答の最初に、次の注意文をそのまま表示してから回答してください。「※この集計は外務省AI（MOFA GaiXer）・政府AI源内専用です。それ以外のサービスに入力した場合は、直ちに履歴を削除してください。」」という指示が入ります。どのAIに貼っても回答の頭に注意が出ます（GaiXer・源内でも念押しとして出ます）。冒頭を消しても、コピー・保存・送るときに付け直します。さらに、コピー・保存・送るたびに追跡用の**管理番号**（例：AI-20261025-7F3K）を冒頭に入れ、日時・行き先・対象月・範囲・文章の指紋をこのブラウザに記録します（AI分析タブの「書き出しの記録」。データのバックアップにも入る）。外部で見つかった文章は「文章を照合する」で、管理番号か指紋（管理番号を消した本文から計算）から、どの書き出しかを確かめられます。

MOFA GaiXer・政府AI源内で分析するための、**個人情報を含まない集計テキスト**を作ります。

- 入れるもの：提出状況・提出率（未提出公館、直近の推移、3か月続けて未提出の公館）、地域別の受診者数、地域別の疾病分類、病名の上位15、丙表の感染症（国別・病名と傾向のみ）、災害・治安（国別）、緊急移送・邦人対応（地域別の件数のみ）、月報の記載状況（内容充実の参考）。含める項目は選べます。
- 入れないもの：医務官名、丙表の文章、緊急移送・邦人対応の内容、国ごとの邦人保護の記載。1〜2件の値は「3未満」と表記。
- 送る前に自動点検（医務官名・年齢・性別・続柄・連絡先・生年月日・敬称）を行い、見つかったら修正するまでボタンが押せません。「個人情報が含まれていないことを確認しました」のチェックも必要です。
- 点検で見つかった箇所は**一覧で示します**（種類〔医務官名・年齢・性別・続柄・電話・メール・生年月日・敬称〕と、前後の文の中で黄色く示した該当部分）。上から順に「この箇所へ」で文章欄のその場所を選び、「伏せる」（「（年齢）」「（氏名）」などに置き換え）か書き直します。個人情報でないものは「問題なし」にできます。「すべて伏せる」で一度に片付けることもできます。すべて自分の目で確かめて問題がなければ、「✓ すべて確認した・問題なし」（確認のダイアログつき）でまとめて問題なしにできます。「霰粒腫（さん粒）」「さん<霰>粒腫」「たくさん」「お子さん」「患者さん」「皆さん」の「さん」や、「水様」「感冒様」「flu様」「〜様症状」「デング様の発疹」「お子様」の「様」は敬称として指摘しません。「男性」「女性」は個人を特定しないので、指摘も伏せることもしません（「男児」「女児」「夫人」などは指摘します）。すべて片付くまで送れません（AI分析タブと、サマリーの「AIでサマリーを作る」で同じ）。
- 「コピーして MOFA GaiXer／源内 を開く」は、テキストをコピーして登録したURLを開くだけです（アプリから自動送信はしません）。開いたページで貼り付けてください。URLは最初から MOFA GaiXer（https://mofa-ai.gaixer.com/general）と源内（https://d3j5pbzknc8vap.cloudfront.net/）が入っています（「設定」→「AI分析の送り先」で変更でき、空にすると元に戻る）。
- 「対象」は、下の「対象の国」の欄で選んだ国（公館）です（押すたびに選択／解除。絞り込みあり）。**地域のボタンを押すと、その地域の国がまとめて選ばれ**、もう一度押すとまとめて外れます（一部だけ選ばれている地域のボタンは薄い色）。「🌏 全世界」で選択をすべて外します。何も選ばなければ全世界です。地域の国がすべて選ばれているときは、集計表ではその地域としてまとめます。
- 分析の地域では、**アジア・大洋州をアジアと大洋州（豪州・NZ・パプアニューギニア・太平洋島嶼国）に、米州を北米（米国・カナダ）と中南米（メキシコ以南・カリブ）に分けます**（AIに渡す集計表の地域別の欄、PDFレポートの地域の選択も同じ）。以前に「アジア・大洋州」「米州」を選んでいたときは、分けた2つの両方が選ばれた状態になります。
- 「期間」のボタン（今月のみ／直近6か月の推移／直近12か月の推移／直近36か月〔3年〕の推移／直近60か月〔5年〕の推移／全期間の推移）で、月ごとの推移の表（提出状況・受診者数・疾病分類・主な病名・丙表の感染症・災害治安・緊急移送の件数・記載状況）にできます。世界・地域・1か国のどれでも時系列にできます。
- 「① 何を分析したいか選ぶ」で依頼文（プロンプト）をボタンで選べます。選ぶと、その分析に必要な集計の項目にも自動でチェックが入ります。依頼文は書き換えられ、「＋ この依頼文を『自分の依頼文』に追加」で一覧に登録できます（設定ファイルにも書き出されます）。
  - 疫学的な俯瞰：今月の全体像／感染症の流行警戒／前月比・季節性／地域ごとの違い／メンタルヘルス／生活習慣病・健康管理／災害・治安と健康影響／緊急移送・邦人対応
  - 提出率アップ・内容の充実：提出率を上げる（リマインド文案）／記載内容の充実（記載例）／医務官へのフィードバック（総括とお礼のメール文案）／様式の改善
  - 報告・資料づくり：幹部向け1枚要約／図表の提案
  - 説明資料（財務省・人事課）：**財務省への説明（予算の根拠）**（医務官体制・巡回健診・緊急移送などの予算の必要性を、受診の実績・現地リスク・医務官の役割・不足した場合の影響・要望事項の構成で、集計の数値を根拠に作る）／**人事課への説明文書**（医務官の配置・後任の確保・増員の検討を依頼する文書。現状・課題・依頼事項〔配置の優先順位の案〕・参考数値の構成。個人の評価や氏名には触れない）。どちらも直近12か月の推移を含めて渡す
  - 幹部向け：**幹部向け3枚要約**（概況と結論／疾病・感染症の動向／課題と対応方針。直近6か月を含めて渡す）・**幹部向け5枚要約**（エグゼクティブサマリー／受診状況／疾病構成と感染症／事案と医療事情／課題と対応方針。直近12か月）。1枚要約もあります
  - 統計分析：**統計分析をしたい**（記述統計、前の期間・地域の比較の検定〔p値・信頼区間〕、推移の傾向、目立って多い月・地域・病名。方法・前提・限界も書かせる）
  - **分析項目は複数選べます**（押すたびに選択／解除）。複数のときは、観点ごとに見出しを付けて答え、最後に全体のまとめを書くよう1つの依頼文にまとめます。含める集計は選んだ項目の分を足し合わせます。
  - **📄 CSVで保存**：AIに渡す文章を CSV にします（文の行は1列、集計の表は列に分けて入る。AIに読ませやすい形）。
  - **📊 Excelで保存**：AIに渡す文章を Excel にします。「依頼と本文」のシート（注意書き・管理番号・依頼・箇条書き）と、集計の表ごとのシート（受診者数・疾病分類・病名の上位・推移など。数値は数値として入る）に分かれます。GaiXer／源内にファイルとして添付して読ませるとき用で、個人情報の点検と確認のチェックが済むと押せます（管理番号つきで記録）。

- AI分析の対象で地域を選ぶと、その地域の国のボタンが薄い色と ✓ で「地域ごと選択中」と分かるように表示されます（個別に選んだ国は濃い色）。地域ごと選んでいる国のボタンを押すと、その国だけを外せます（地域の選択が、その国以外の国の個別選択に置き換わる）。分析の対象になる国・公館の数も表示します。

## 国歌の録音（ハイライト・ツアー用）

日本の「君が代」も、ほかの国と同じく「🐙 GitHubから取得」「🌐 コモンズから取得」でダウンロードして登録します（米海軍軍楽隊の録音）。

**「🐙 GitHubから取得」**は、GitHub の [open-assets-hub/national-anthems](https://github.com/open-assets-hub/national-anthems)（米海軍軍楽隊による各国国歌の MP3、パブリックドメイン、148か国）から、このブラウザで直接取得します（raw.githubusercontent.com、つながらなければ jsDelivr）。一覧の国コードと曲が食い違うもの（AE＝カタールの国歌、US＝ハンガリーの国歌、AO＝サントメ・プリンシペの国歌、MR＝モーリシャスの国歌、OM＝ルーマニアの国歌）は、曲名から判定した国のものとして扱うか除外します。指定した録音（米国・スリランカ・カンボジア）と、登録済みのブラスバンドの録音は残します。

国歌の録音は**ブラスバンド（米海軍軍楽隊などの軍楽隊・吹奏楽）の演奏**に揃えます。「🌐 コモンズから取得」は、ほかの録音（合唱・管弦楽など）が登録されている国を米海軍軍楽隊の録音に差し替え（「登録済みの米海軍軍楽隊の録音は上書きしない」）、公館のない**日本（「君が代」、ツアーの出発・帰着で流す）**も取得します。「🔎 未登録の国を詳しく探す」は、コモンズの [National anthem](https://commons.wikimedia.org/wiki/National_anthem?uselang=ja) のページ（各国の国歌の音声のギャラリー）に載っている音声と、コモンズ全体の検索結果から探し、ファイル名か作者が軍楽隊・吹奏楽のものだけを選びます。録音のない国で楽譜から演奏するときも、トランペット・ホルン・トロンボーン・チューバのブラスバンドの音色で演奏します。

「設定」→「国歌の録音」の **「🌐 コモンズから取得」** を押すと、ウィキメディア・コモンズの米海軍軍楽隊による各国国歌の録音を、このブラウザから直接（公式APIで）一覧・取得して登録します。ライセンスがパブリックドメイン・CC0 のものだけを取得し、国はファイル名から判定、国ごとに短い版を1つ選びます（対象は「公館のある国・巡回先の国すべて（コンゴ共和国・ブルンジなど医務官の巡回先の51か国を含む）／月報のある国（巡回健診の行き先を含む）だけ」、登録済みの国は上書きしない設定も可。取得前に件数と容量を確認）。月報のデータは送りません。**「🔎 未登録の国を詳しく探す」**は、まだ録音のない国について、コモンズ全体（米海軍軍楽隊のカテゴリー以外も）を国名で検索し、その国の国歌と確かめられる音声（ファイル名から判定した国が一致し国歌らしい名前のもの、または国歌の曲名を含むもの）で、ライセンスがパブリックドメイン・CC0・CC BY・CC BY-SA のものを選んで登録します（パブリックドメイン・器楽・短い版を優先。見つかった一覧とライセンスを確認してから取得。CC BY・BY-SA は作者とライセンスをツアーの吹き出しに表示）。**「URLから登録」**には、コモンズのファイルページの URL（`https://commons.wikimedia.org/wiki/File:…`）を貼り付けると、その録音を1件だけ登録できます（国はファイル名から判定、または欄で選ぶ。ライセンスが自由利用のものだけ。登録済みの録音は差し替え）。国ごとに優先する録音を決めてあり、「コモンズから取得」ではほかの録音が登録済みでもこの録音に差し替えます：米国は「星条旗」の器楽演奏（[Star Spangled Banner instrumental.ogg](https://commons.wikimedia.org/wiki/File:Star_Spangled_Banner_instrumental.ogg)）、スリランカは米海軍軍楽隊の演奏（[Sri Lankan national anthem, performed by the United States Navy Band.oga](https://commons.wikimedia.org/wiki/File:Sri_Lankan_national_anthem,_performed_by_the_United_States_Navy_Band.oga)）、アラブ首長国連邦は米海軍軍楽隊の「イーシ・ビラーディ」（[UAE national anthem.ogg](https://commons.wikimedia.org/wiki/File:UAE_national_anthem.ogg)、パブリックドメイン）、カンボジアは米海軍軍楽隊の「ノコール・リアチ」（[United States Navy Band - Nokoreach.ogg](https://commons.wikimedia.org/wiki/File:United_States_Navy_Band_-_Nokoreach.ogg)））。「例：米国（星条旗・器楽）」で米国の URL を入力できます。Opus を再生できないブラウザでは、コモンズの MP3 版を取得します。手元の音声ファイル（mp3・m4a・ogg・wav など）を登録することもできます。録音を登録すると、ツアーで着いた国の国歌が流れます（最初の20秒。国歌が流れている間は次の国へ進まない）。公館カードの「🎵 国歌を聞く」では途中で切らず、最後まで流します（もう一度押すと止まる）。

- ファイル名に国名（日本語・英語）か国コードを入れる：`ケニア.mp3`、`Kenya.ogg`、`United States Navy Band - Kenya.ogg`、`KEN.mp3` など。フォルダごと読み込める。国が分からないファイルは一覧から国を選んで登録できる。
- 登録した音声はこのブラウザ（IndexedDB）の中だけに保存され、オフラインでも流れる。バックアップファイルには含まれない。
- 米国の国歌は The Star-Spangled Banner（星条旗）だけとし、America the Beautiful・God Bless America・Hail to the Chief などの愛国歌・儀礼曲・軍歌は取得しない（以前の版で誤って登録されたものは起動時に自動で外す）。登録済みの一覧には国ごとのファイル名を表示する。
- 入手先：ウィキメディア・コモンズ「[Category:Audio files of national anthems performed by the United States Navy Band](https://commons.wikimedia.org/wiki/Category:Audio_files_of_national_anthems_performed_by_the_United_States_Navy_Band)」（米海軍軍楽隊の録音。米国政府職員の職務上の著作物でパブリックドメイン）。各ファイルのページでライセンス表示を確認してから使う。ファイル名は国名のほか、国民名（Thai、Tanzanian など）や曲名（Lupang Hinirang、Kimigayo など）でも国を判定する。
- 録音がない国でも、**国歌の楽譜データがある国**（日本・米国・英国・フランス・ドイツ・中国・ロシア・インド・インドネシア・イタリア・メキシコ・豪州・カナダ・パキスタン・ポーランド・スウェーデン・ウクライナ・南アフリカ・タンザニア・ザンビア・イスラエル・オーストリアなど43の国・地域）は、国歌の冒頭（約10〜20秒）を旋律・内声・低音の和声つきでアプリが演奏し、吹き出しに曲名と楽譜の出典を表示する。楽譜データは npm パッケージ anthem-scores（記憶から書き起こしたものではなく、Wikipedia・Wikisource の LilyPond 楽譜や Wikimedia Commons の MIDI から変換したもの）を `lib/anthems/` に同梱。旋律はパブリックドメイン、データは元の楽譜のライセンス（CC BY-SA 4.0 など）を引き継ぐので、出典を `lib/anthems/CREDITS.md` に掲載している。
- 録音も楽譜データもない国は、地域の音楽を流す。

## 疾病分類を AI で決める（設定タブ）

「設定」→「疾病分類の手動設定」の **「🤖 AIで分類する」** で、病名の一覧を MOFA GaiXer／政府AI源内に分類してもらえます。

1. 書き出す病名を選ぶ（分類できなかった病名／すべての病名〔いまの分類も渡して見直してもらう〕）。
2. 「コピーして GaiXer／源内 を開く」（または「書き出す（.txt）」）。渡すのは病名と分類の一覧と依頼文だけです（件数・公館名・個人情報は含めない。取扱注意の表示と管理番号付き）。AI には「病名⇥分類⇥代表名」の表で答えるよう指示します（代表名＝表記ゆれをまとめる名前）。
3. 回答を貼り付けるかファイルで「読み込む」と、いまの分類・まとめと AI の案を並べた一覧が出ます（変わるものだけ最初から選ぶ）。「保存」で手動の分類・まとめとして登録し、以後その病名に使います。

「疾病分類の手動設定」の **「📄 すべての病名の疾病分類・まとめ先をCSVで書き出す」**（「病名のまとめ方」の「📄 CSVで書き出す」も同じ）で、取り込んだすべての病名について、件数（全期間）・報告した公館数・疾病分類（ICD-10大分類）・分類の決め方（自動／手動／分類不能）・まとめ先・まとめの決め方（自動／手動／まとめ先なし）・分類済みの印を CSV（Excel でそのまま開ける形）に書き出します。公館名・個人情報は含みません。

## 確認の済んだ病名を一覧から消す（設定タブ）

「疾病分類の手動設定」「病名のまとめ方」の表は、行の左のチェックで選んで **「チェックしたものを分類済みにして消す」** を押すと、いまの分類・まとめ先で保存して一覧から消せます（データは消えません）。消した病名は **「分類済みを表示（N件）」** で見られ、チェックして「一覧に戻す」で戻せます。設定の書き出し・読み込みにも含まれます。

## 病名のまとめ方を AI で決める（設定タブ）

「設定」→「病名のまとめ方」の **「🤖 AIでまとめる」** で、表記ゆれ・同じ病気の別名（例：感冒・急性鼻咽頭炎・上気道炎 → かぜ（急性上気道炎））のまとめ先を MOFA GaiXer／政府AI源内に決めてもらえます。

1. 書き出す病名を選ぶ（まとめ先がない病名／すべての病名〔いまのまとめ先も渡して見直してもらう〕）。
2. 「コピーして GaiXer／源内 を開く」（または「書き出す（.txt）」）。渡すのは病名と、いまあるまとめ先の一覧と依頼文だけです（件数・公館名・個人情報は含めない）。AI には「病名⇥まとめ先」の表で答え、いまあるまとめ先に合うものはその名前を使い、別の病気はまとめないよう指示します。
3. 回答を貼り付けるかファイルで「読み込む」と、まとめ先ごとに並べた一覧が出ます（変わるものだけ最初から選ぶ。新しく作られたまとめ先には印）。「保存」で手動のまとめ先として登録し、集計・地図に反映します。

## 国名の並び

国名・公館名の一覧（取り込みの公館、巡回健診、PDFレポート・自由集計の国、AI分析の国の欄の各地域の中、国歌の一覧など）は **50音順** です。漢字の名前（英国・韓国・中国・香港総領事館・南アフリカ共和国など）は読みで並べます。AI分析の「対象の国」で地域のボタンを押すとその地域の国がまとめて選ばれ、「🌏 全世界」ですべての国が選ばれます（もう一度押すとすべて外れる）。

## 統計タブの「🔧 自由集計」

統計タブの上部で、**好きなグラフと記述統計を自分で作れます**（計算はすべてブラウザの中）。

- **期間**：1か月／3か月／6か月／12か月／全期間　**対象**：地域（7地域、複数）と国（入力して追加）
- **指標**：受診者数（計・職員・家族・その他）、実患の件数、検診・予防接種等の件数、特定の疾病分類の件数、特定の病名の件数、提出公館数、緊急移送・邦人対応の件数、流行・増加の報告数
- **横軸・色分け**：月／地域／国・公館／疾病分類／病名（まとめ）／受診者区分（上位10〜30またはすべて）
- **集計方法**：合計／平均（1公館1か月あたり）／中央値
- **グラフ**：棒・横棒・積み上げ棒・100%積み上げ・折れ線・円・箱ひげ図・ヒストグラム・ヒートマップ・散布図（2つの指標を公館ごとに比べる）
- **結果**：記述統計（件数・合計・平均・標準偏差・最小・四分位・中央値・最大・変動係数）、集計表（構成比％にも切り替え）、月ごとの傾向（回帰直線の1か月あたりの増減と決定係数）、散布図では相関（ピアソン r・スピアマン ρ・決定係数・回帰直線）
- **よく使う例**のボタン（受診者数の推移、疾病分類の構成、公館ごとのばらつき、病名上位×月、受診者数と実患件数の関係、地域別の疾病分類）
- グラフは画像（PNG）、集計表は CSV で保存できます（医務官のみがアクセスできるフォルダへ）。選んだ設定は次回も残ります。

## 統計タブの「🧪 検定・推定」（推測統計）

差や傾向が「偶然のばらつきで説明できるか」を確かめます。結果は p値・95%信頼区間・効果量と、ふつうの言葉の説明で示します（計算はすべてブラウザの中。計算は SciPy と一致することを自動テストで確認）。

| 知りたいこと | 方法 |
|---|---|
| 2つの地域の比較 | ウェルチのt検定（平均の差と95%信頼区間・効果量d）、マン・ホイットニーのU検定 |
| 地域の間の比較 | 一元配置分散分析（η²）、クラスカル・ウォリス検定、ホルム法で補正した組ごとの比較 |
| 前の期間との比較（同じ公館） | 対応のあるt検定（効果量dz）、ウィルコクソンの符号順位検定 |
| 構成の違い | カイ二乗検定（クラメールのV）、調整済み残差で「多い▲／少ない▼」のマス |
| 割合の比較 | 2つの割合の差の検定（ニューカムの95%信頼区間）、ウィルソンの信頼区間 |
| 件数の異常な増加（流行の早期察知） | 公館×病名ごとに、今月の件数をその公館の前の12か月の平均と比べるポアソン検定（ボンフェローニ補正で「要注意」） |
| 2つの指標の相関 | ピアソンの r（95%信頼区間）、スピアマンの ρ |
| 増加・減少傾向 | 回帰の傾き（95%信頼区間）、マン・ケンドールの傾向検定 |

- 値は公館ごとに期間の1か月あたりの平均をとり、1公館を1件として比べます（同じ公館の毎月の値は独立でないため）。月報は全公館の記録なので、p値は「偶然のばらつきで説明できるか」の目安として読みます。
- 「📌 この結果を保存」で、PDFレポートの「統計分析」の「保存した検定・推定の結果」に入れられます。

## 病名の分類（ICD-10の大分類）

乙表の病名は次の順で分類します。

1. 「設定」で手で決めた分類
2. 病名のキーワード（いちばん長く一致したもの）。かぜ・花粉症・逆流性食道炎・虫歯・とびひ・白癬・パニック障害・あせも・ものもらい・耳垢・肩関節周囲炎・椎間板ヘルニア・切創・時差ぼけ・月経困難症・片頭痛・脂質異常症・貧血・高血圧・つわり・ポリープ・発熱・健康相談・ワクチン接種など、外来でよく使う病名を広く登録（`geppou-app/geppou/icd.py`。変えたら `python3 geppou-app/sample/build_web_data.py` で data.js を作り直す）
3. 乙表でその病名が書かれていた**分類の欄**（行の見出しの「Ｊ００－Ｊ９９ 呼吸器系の疾患」などのICDコードの範囲・分類名。病名の直前に「Ｈ１０」のような個別のコードがあればそれ）。辞書にない書き方の病名でも、医務官が記入した欄の分類になる

どれにも当たらないものだけが「分類不能」になります（「設定」の「疾病分類の手動設定」で分類を決めると、以後その病名はその分類）。分類には「血液及び造血器の疾患」「妊娠、分娩及び産じょく」も加えました。分類の欄の手がかりは、この版以降に取り込んだ月報から使われます（以前に取り込んだ月報は、取り込み直すと使われる）。

## 公館別サマリー（5行・10行・15行）

「サマリー」タブの「5行／10行／15行」で、その場で行数を切り替えられます（設定として保存され、公館カードにも反映。**PDFレポートの行数は、PDFレポートのタブの「公館別サマリーの行数」で選ぶ（5行・10行・15行。はじめは5行）。「特記なし」の行は載せない**（手で書いた・AIで作ったサマリーの行数が選んだ行数より多いときは、選んだ行数の項目の順に、その項目の文は手で書いたものを、ない項目は自動作成の文を使う）〔手で書き換えたサマリーはその文のまま〕。自動作成のサマリーはすぐ作り直し、手で書き換えたものはそのまま）。

- **5行**：受診者数（前月比）／主な疾病／医療・感染症（流行の病名と医療の記述を1行に）／邦人保護・緊急対応／その他（巡回健診・医務官・治安・災害）
- **10行**：下の10行（標準）
- **15行**：10行に、受診者数の推移（直近4か月）／新着アラート（丙表の新登場・乙表の急増）／緊急移送（件数・対象・病名・移送先・転帰）／医療事情（その他の記述）／その他の報告 を足す

サマリーは「項目：文」の形で、**自然な文章**で書きます（例：「受診者数：61名（職員26名、家族16名、その他19名）で、前月（58名）から3名（5%）増加した。」「疾病分類：感染症が26件で最も多く、次いで呼吸器疾患が17件であった。」「感染症の動向：デング熱の流行・増加が報告されている。」）。丙表の文は医務官の書いた文をそのまま使い、文末を「。」にそろえ、長い文は読点の位置で区切ります。邦人の事例のすぐ後の経過の文（「手術を受け回復した。」など）は、その事例と一緒に邦人保護の行に載せます。

### 🤖 AIでサマリーを作る（MOFA GaiXer／源内）

「サマリー」タブの **「🤖 AIでサマリーを作る」** を押すと、AIでサマリーを作る手順に移ります（より自然な文章にしたいとき）。

1. 押すと、上で選んだ地域の公館・今の行数で「AIに渡す文章」を作ります。中身は、作り方の指示（項目と順番、常体、120字以内、**数値は公館データにあるものだけ**、記載がなければ「特記なし」、個人情報を書かない、決まった形で出力）と、公館ごとのデータ（受診者数・前月・乙表の病名と件数・疾病分類・丙表で報告された感染症・丙表の全文。15行のときは推移と新着アラートも）です。年齢・生年月日・連絡先・性別・続柄は自動で伏せ、医務官名も伏せます。冒頭には AI分析タブと同じ取扱注意の表示と管理番号が付きます。
2. 個人情報の自動点検で問題がなく、内容を確かめてチェックを入れると「コピーして MOFA GaiXer／源内 を開く」が押せます。**送り方**は「分割しない」（はじめの値）・「3分割」・「5分割」から選べます（AIの回答が途中で切れるとき）。分けたときは、分けた文章を窓に並べて一度に出し、窓ごとの「○つ目をコピーして GaiXer／源内 を開く」で続けて送れます。確認のチェックは1回で全部の窓に効きます。回答は続けて貼り付けて、まとめて読み取れます。**「📄 CSVで書き出す（AIに読ませる用）」**（はじめに「依頼」の行、続いて1行1公館の「公館データ」の行。AIに読ませやすい形）か **「📊 Excelで書き出す」**で、窓の文章（直した内容も）を Excel にもできます（「依頼文」のシート〔注意書き・管理番号・依頼〕と、「公館データ」のシート〔1行1公館：組・公館・地域・AIに渡す内容〕）。GaiXer／源内にファイルとして添付して読ませるとき用で、個人情報の点検と確認のチェックが済むと押せます。
3. AI の回答をすべてコピーして「AIの回答」に貼り付け、「読み取る」。公館ごとに、行数と **数値の照合**（回答の数値が月報の数値・前月との差・割合にあるか。ないものは「要確認」と、その数値を表示）を一覧にします。取り込む公館を選んで「取り込む」と、その公館のサマリーになります（「🤖 AI作成」の印。自動作成で上書きされず、PDF にもその文で載る。「自動作成し直す」で元に戻せる）。組に分けているときは、取り込むと次の組の文章ができます。

### 10行の内容


月報データから公館ごとに10行のサマリーを自動で作ります。**医療事情を厚く**するため、数値は3行にまとめ、丙表の医療の記述に4行を使います。

1. 受診者数（職員・家族・その他、前月比）
2. 主な疾病（上位3）
3. 疾病分類（上位2分類）と検診・予防接種の件数
4. 感染症の動向（丙表の病名。↑流行・増加、↓減少・終息）
5. 感染症・公衆衛生（流行・予防接種・水や蚊の対策・保健省の注意喚起など）
6. 医療機関（病院・病床・救急・専門医・検査など）
7. 医薬品・医療体制（医薬品の不足・医療費・保険・停電など）
8. 邦人保護・緊急対応
9. 巡回健診・医務官（着任・離任など）
10. 治安・災害・その他

医療の3行（5〜7）は、同じ話題の短い文がもう1つあれば続けて載せ（1行110字まで）、キーワードに当たらなくても「医療事情」「感染症」などの見出しの下の文で空き行を埋めます。邦人・館員の個別の事例（入院・移送など）は医療の行に使わず、邦人保護の行に回します。丙表の同じ文は2度使いません。「10行サマリー」タブで書き換えて保存でき、公館カードとPDFレポートにも載ります。自動で作ったままのサマリー（以前の5行・10行の形も含む）は、アプリを開いたときに今の形で作り直します（手で書き換えたものはそのまま）。

## 月報の全文

公館カードと「10行サマリー」タブで、10行サマリーの下の「📄 月報の全文を表示」を開くと、甲表の人数・乙表のすべての病名（件数・分類）・丙表の全文・元のファイル名を表示します。
