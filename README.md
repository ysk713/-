# メンタルヘルス・マネジメント検定 Ⅰ種（マスターコース）問題集

Ⅰ種（人事労務管理スタッフ・経営幹部向け）対策のオリジナル予想問題集です。
公式テキストの章立てに沿った**選択問題（4肢択一）45問**と、**論述問題2問（採点ポイント・解答例つき）**を収録しています。

> ⚠️ 本問題集は出題傾向を踏まえて作成した**オリジナルの類題**であり、過去問や公式問題ではありません。
> 法令・指針は 2026年10月時点の内容に基づいています。受験前に最新の公式テキスト・実施要項・法改正情報で必ず確認してください。

## 使い方

1. 各章ファイルの問題を解く（解答・解説は折りたたみ表示になっているので、クリックして開く）
2. 間違えた問題は「関連知識」まで読み、公式テキストの該当箇所で確認
3. 論述問題は時間を計って実際に書き、採点ポイントで自己採点
4. 直前期は [頻出数字・法改正まとめ](matome.md) で数字を総復習
