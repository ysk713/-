# 司法試験 合格ノート

司法試験の学習用アプリです。ブラウザで `index.html` を開くだけで動きます（インストール・外部通信なし）。

公開URL（GitHub Pages）: https://ysk713.github.io/-/shihou-app/

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 試験日までの日数、今日の解答数と目標、連続学習日数、科目別の正答率、直近12週の学習カレンダー |
| 短答 | 憲法・民法・刑法の肢別演習（91肢）。科目・分野・未解答/間違えた肢/苦手な肢で絞り込み。解説つきの1肢ずつ形式と、時間制限つきの本番形式 |
| 復習 | 間違えた肢を翌日に、正解した肢は 1→3→7→14→30→60日 の間隔で出し直す |
| 論文 | 7科目14問の答案構成トレーニング。タイマー、構成メモ（自動下書き保存）、論点チェックリストで自己採点 |
| 記録 | 分野別正答率、間違えやすい肢、バックアップ（書き出し・読み込み） |

キーボード操作：`O` で○、`X` で×、`Enter` で次へ。

## 問題を追加するには

`data.js` の `tanto`（短答）や `ronbun`（論文）に同じ形式で追記します。

- 短答：`{ id, s: 科目, f: 分野, q: 問題文, a: true(○)/false(×), e: 解説, r: 根拠条文・判例 }`
- 論文：`{ id, s: 科目, title, min: 目安分, facts: 事例, ask: 設問, points: [{ t: 論点, d: メモ }], tips }`

## 注意

- 収録問題は出題傾向を踏まえたオリジナル問題で、過去問ではありません。法令は2026年10月時点の内容によります（拘禁刑、2017年債権法改正、2024年家族法改正〔共同親権〕などを反映）。
- 学習記録はブラウザの localStorage に保存されます。ブラウザのデータを消すと記録も消えるので、記録画面から書き出しておいてください。

## 端末に保存して使う（オフライン）

[`shihou-note.html`](shihou-note.html) は、アプリ全体（問題データ込み）を1つにまとめたファイルです。スマホやPCに保存し、ブラウザで開けばネットにつながっていなくても使えます。
`index.html`・`style.css`・`data.js`・`app.js` を直したら `python3 shihou-app/build.py` で作り直してください。
