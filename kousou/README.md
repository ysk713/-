# 個人用医薬品購送 書類審査ツール

在外公館から届く「個人用医薬品購送」三点セット（申込書→診断書→指示書）を下判定し、1人1PDF（`YYYYMMDD氏名.pdf`）にまとめるツールです。**最終判断は必ず人が行ってください。**

## 職場PCで使う（インストール不要・外部送信なし）

1. **https://ysk713.github.io/-/kousou/** を Edge または Chrome で開きます。ネットにつながらないPCでは、このページを「名前を付けて保存」（または `index.html` をダウンロード）してダブルクリックで開きます。
2. **① 読込・分割**
   - 日次スキャンPDFをドロップします。白紙ページ（インク密度0.5%未満）は自動で除外されます。
   - 「1人3枚ずつ」で自動割当した後、ずれている箇所を直します。ページをクリックしてキー操作します：`1` 申込書、`2` 診断書、`3` 指示書、`4` 委任状、`S` ここから新しい患者。
3. **② 入力・審査**
   - 原本の画像を見ながら、日付・職員コード・署名/押印・薬剤などを入力します。
   - 判定結果（エラー相当／要確認）はその場で更新されます。
   - 原本と照合したら「**確認済み**」にチェックを入れ、「**3点セットPDFを作成**」を押します。その人の申込書→診断書→指示書を1つのPDFにまとめて、`YYYYMMDD氏名.pdf` の名前で保存します（Edge/Chromeでは保存ダイアログが開きます）。エラー相当がある場合や書類が足りない場合は、作成前に確認が出ます。
4. **③ 出力**
   - 「ZIP一括ダウンロード」で、1人1PDF・`判定結果.md`・`判定一覧.csv` をまとめて保存します。
   - ZIP内の日本語ファイル名はUTF-8で格納するので文字化けしません。

途中で止めるときは「作業を保存」を押します（JSON。PDFは含みません）。再開するときは、同じスキャンPDFを読み込んでから「作業を読込」を押します。

### 外部に送信しない仕組み

ライブラリ（pdf.js・pdf-lib・JSZip）はすべてHTMLに埋め込んであります。さらにページの Content-Security-Policy で外部への通信を禁止しているので、スキャン画像や入力内容がPCの外へ出ることはありません。インターネットに接続していないPCでも動きます。

### 判定ルール・薬品マスタ

- **薬品マスタ**は次の2つを合わせたもの（約220品目）です。同じ薬が両方にある場合は購送審査側が優先されます。
  - 購送審査のマスタ（`python/kousou/drug_master.json`）
  - 診断書・指示書 作成支援アプリの薬剤マスタ（`shindansho/drugs.js`）

  あわせて、同アプリの規制薬リスト（向精神薬・麻薬・覚醒剤原料など）も判定に使います。マスタに無い薬でも、向精神薬や購送できない薬として検出します。
- 画面の「薬品マスタ」で書くのは、**追加・上書きしたい品目だけ**です（そのPCのブラウザに保存）。既定マスタが更新されても、追加分はそのまま残ります。
- 「判定ルール」も画面から編集できます。
- 既定値を変えたら `python web/build.py` でHTMLを作り直します。**`shindansho/drugs.js` を直したときも作り直しが必要**です。
- **患者名を含む設定（向精神薬の特別許可など）はリポジトリに入れず、画面から各PCで追加してください。**

チェック項目の内容：

- 日付・有効期限
- 職員コード・公館コード
- 申込書の様式（11項目版）・同意チェック
- 委任状
- 診断書の用法・用量
- 診断書⇔指示書の1日使用量
- 数量
- 規格の実在性
- 1日用量の上限
- 保険適応
- 向精神薬（10/1以降は購送不可）
- 新薬14日
- 28日周期
- 署名・押印（9/4改定・10月申込から厳格運用、キューバ・ジブチ例外）
- 原本の使い回し
- 前回バッチとの比較

## 開発

```
web/src/        画面（index.html, app.js）と判定ロジック（rules.js）
web/vendor/     pdf.js 3.11.174 / pdf-lib 1.17.1 / JSZip 3.10.1（各LICENSE同梱）
web/build.py    1ファイルのHTMLに組み立てて index.html を出力
python/         Python版（Claude APIで画像を読み取る版。職場では使わない。薬品マスタは drug_master.json のみ）
```

```bash
python web/build.py
```

```bash
node web/test/rules.test.js && node web/test/master.test.js
```

```bash
python web/test/make_scan.py /tmp/scan.pdf && node web/test/e2e.js /tmp/scan.pdf /tmp
```

テストデータはすべて架空です。**実際のスキャンや患者情報はこのリポジトリに入れないでください**（`.gitignore` でPDF等を除外しています）。
