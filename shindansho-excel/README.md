# 診断書・指示書 Excel版

https://ysk713.github.io/-/shindansho-excel/ からダウンロードできます（`shindansho-shijisho.xlsx`）。

- 個人用医薬品購送で使う「診断書」「指示書（様式B）」を作るExcelファイル。マクロなし（.xlsx）、外部への通信なし。
- 「入力」シートに入れると「診断書」「指示書」シートに反映される。用法は「分n」の書き方、日数は薬ごと（全部同じなら指示書の下に1つ、違えば薬ごと）、後発医薬品への変更不可は薬ごと（J列）。用量（1回量）に文字を入れると自由記載になる。
- 「入力」シートの整合性チェック：基本情報の入力、有効期限（3か月）、服用薬の入力、購送できない剤形、署名押印。④⑤は問題のある薬の行と項目を示し、未入力・誤りのある黄色い欄は赤くなる（条件付き書式）。
- 発行日は入力シートの一番上（赤枠）に入力する。
- 生年月日・発行日は1つの欄（「1980/4/1」「1980年4月1日」も可）。公館コードの欄には国名も入れられる。補足の右に総量（自動計算、印刷しない）。
- 使い方：配ったファイルは白紙の原本として残し、患者ごとに「名前を付けて保存」。「診断書」「指示書」のシート見出しを Ctrl で2つ選んで印刷すると2枚まとめて出る。
- 用量の上限・保険適応・向精神薬・麻薬の自動チェックはない（ブラウザ版の「診断書・指示書 作成支援」にはある）。

## ブラウザ版との関係

2026-11-06 にブラウザ版（`shindansho/`）から分離した。別のものとして管理し、ブラウザ版を直してもExcel版は自動では変えない。Excel版は仮の医師による使用テストで改良する。

## 毎日の使用テスト

`python3 shindansho-excel/tests/excel_test.py` で、入力シートに値を入れて LibreOffice で再計算し、診断書・指示書の表示・整合性チェック・印刷のページ数（A4・US Letter で各1枚）を確かめる（LibreOffice・pdfinfo・openpyxl が必要）。毎日、架空の医務官になりきった入力例でも試し、記録を `docs/daily/` に残す。計算の誤り・文字の切れ・古い説明などは直し、様式や入力欄の作りを変えるものは提案としてユーザーの判断を待つ。

## 10人のアバター医師の模擬

`python3 shindansho-excel/tests/sim10.py [人数] [種]` で、架空の医師10人（専門・Excelの慣れ・用紙がばらばら）が2件ずつ書類を作ったとして、わざと入れた誤り（15%）の検出、正しい書類への誤った警告、エラー表示、ありえない1日量、印刷が1枚に収まるかを数える（約20秒）。Excelが苦手な人の入れ方（全角数字・「1錠」・「30日」・ひらがなのフリガナ・コピーした改行・年の欄への日付の貼り付け・「1/2」など）も含む。毎日の試用（1日3回）で毎回実行する。
