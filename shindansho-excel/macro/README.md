# 薬品名を入力したそばから候補を出すマクロ（試作・未確認）

マクロを使わない版（.xltx / .xlsx）では、Excel の仕組み上、入力中に候補を出せません（数式は入力を確定してから計算されるため）。
マクロを使えば、薬品名の欄の上に「候補つきの入力枠（コンボボックス）」を重ね、入力したそばから候補で補えます。
**このマクロは Excel のない環境で書いたもので、まだ動かしていません。** Windows の Excel で試してから使ってください。

## 作り方（Windows の Excel、1回だけ）
1. 最新の `shindansho-shijisho.xlsx` を開く。
2. Alt＋F11 で VBA の画面を開く。
3. 左の一覧の「入力」シートをダブルクリックし、`入力シート用.txt` の中身を貼り付ける。
4. 左の一覧の「ThisWorkbook」をダブルクリックし、`ThisWorkbook用.txt` の中身を貼り付ける。
5. VBA の画面を閉じ、［名前を付けて保存］で「Excel マクロ有効テンプレート（*.xltm）」または「Excel マクロ有効ブック（*.xlsm）」として保存する。
6. いったん閉じて開き直し、「コンテンツの有効化」を押す。薬品名の欄（B24〜B33）を選ぶと入力枠が出る。

## 気をつけること
- インターネットから取ったマクロ入りファイルは、Windows が自動でマクロを止めます。職場の中で作って共有フォルダで配るほうが安全です（作った人のPCで上の手順を行う）。
- 職場の設定でマクロや ActiveX（入力枠の部品）が止められていると動きません。
- Mac の Excel では動きません（ActiveX がないため）。
- 候補は「頭の文字が合う」もの（例：アム → アムロジピン錠…）。商品名や途中の文字で探すときは、表の下（34行目）の候補表示を使います。
- 入力枠で選んだあとは、ほかの欄をクリックするか Tab キーで移ります。
