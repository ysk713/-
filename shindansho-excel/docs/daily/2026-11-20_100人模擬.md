# 2026-11-20　Excel版 100人の医師による模擬とコメント

ユーザーの依頼「100人の医者にテストさせてコメントがほしい」に応えた記録。
**ここでの医師はすべて架空（AIが医師になりきったもの）で、実在の医師の意見ではない。** 数字は実際にファイルへ入力して計算・印刷した結果。コメントは、今のファイルの実際の動きをもとに、立場ごとに出そうな声をまとめたもの。

## 1. 模擬の結果（実測）
- 架空の医師 100人が2件ずつ、計200件の診断書・指示書を作った（10人ずつ10回）。
  - 専門：内科・精神科・小児科・皮膚科・整形外科・循環器内科・産婦人科・耳鼻咽喉科。
  - Excelの慣れ：苦手が約半分、普通・得意が約4分の1ずつ。
  - 苦手な人の入れ方を混ぜた：全角数字、「1錠」「30日」のような単位つき、薬品名の後ろの改行、用法の全角。
- わざと入れた誤り：**33件すべて見つけた**（含有量なし・液体・日数0・一覧にない公館コード・生年月日が後・11件目・不均等の数違い・病名なし）。
- 正しい書類への誤った警告：**0件**。
- エラー表示（#VALUE! など）：**0件**。ありえない1日量：**0件**。
- 印刷が1枚に収まらない書類（A4・Letter）：**0件**。

## 2. 模擬の医師のコメント（架空）

### よい点
- 「発行日が一番上にあって、最初に入れればいいと分かる。」（内科・苦手）
- 「灰色の例を見ながら入れられるので、何を書くか迷わない。」（小児科・苦手）
- 「『朝夕食後』と書くだけで1日量と総量が出る。『分2』を考えなくていいのが楽。」（循環器内科・普通）
- 「全部同じ90日分なら上の一括の行に入れるだけで済み、10剤でもすぐ終わる。」（内科・得意）
- 「④が『（3）単位』のように行と項目を教えてくれるので直す場所がすぐ分かる。」（精神科・苦手）
- 「全角で入れても、『1錠』と単位を付けても計算してくれるのはありがたい。」（耳鼻咽喉科・苦手）
- 「漢方42包・湿布28枚の倍数か知らせてくれて、日数の直し方まで出るのがよい。」（整形外科・普通）
- 「吸入・貼付が診断書の結びにも書き分けられ、そのまま出せる文章になっている。」（産婦人科・普通）
- 「A4でもLetterでも1枚に収まる。」（米州の公館・普通）

### 迷った点・困った点
- 「薬品名の▼は候補が多すぎて探しにくい。商品名（ノルバスク・リリカなど）で探せない。」（内科・苦手）
- 「印刷のとき、Ctrl を押しながらシート見出しを2つ選ぶ操作が分かりにくい。」（皮膚科・苦手）
- 「入力したあと『名前を付けて保存』を忘れて、原本に上書きしそうになった。」（小児科・苦手）
- 「入力シートが横に長く（P列まで）、小さいノートPCでは右の『朝・昼・夕・寝る前』の欄が見えない。」（精神科・苦手）
- 「頓服の行は、日数の欄に『回数』を入れると分かるまで少しかかった。」（整形外科・普通）
- 「薬品名の書き間違い（チラージン）は印刷では直るが、入力欄は直らないので、直ったのか不安。」（内科・普通）
- 「用量の上限や保険適応のチェックがない。そこはブラウザ版でないと分からない。」（循環器内科・得意）
- 「湿布を1日2枚使う人は、28の倍数より56枚単位のほうが実際に近い。7枚1パックで考える公館もある。」（整形外科・得意）
- 「医務官の名前は手書きでよいが、印刷したい人もいるのでは。」（耳鼻咽喉科・普通）
- 「ベータ版の表示があるので、しばらくは今までの書類と見比べるつもり。」（内科・得意）

## 3. コメントから出た提案（ユーザーの判断待ち）
1. **原本に上書きしない形で配る**：テンプレート形式（.xltx）にすると、開くたびに新しいファイルになり、原本が上書きされない。
2. **印刷をもっと簡単に**：診断書・指示書を1つのシートに縦に並べた「印刷用」シートを作れば、そのシートを印刷するだけで2枚出る。
3. **薬品名の▼に商品名も**：「アムロジピン錠5mg（ノルバスク）」のように商品名を添える。または、よく使う100品目ほどに絞った短い候補にする。
4. **入力シートを小さい画面向けに**：「朝・昼・夕・寝る前」の欄を表の近くに寄せる、または列幅を詰める。
5. **医務官名の印刷**：入力した医務官名を、署名欄の横に印刷するかを選べるようにする（今は印刷しない決まり）。
