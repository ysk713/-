# 2026-11-28 Excel版 1000件の試行（模擬）

ユーザーの依頼「1000回試行」。10人の模擬（sim10.py）を4本並行で、12〜18人ずつ32回実行した（半分は「高齢」＝Excelが苦手な人を多めにした設定）。対象は、申込書・委任状のタブを入れた最新の版。

| 項目 | 結果 |

| 架空の医務官 | 552人 |

| 正しい書類への誤った警告 | 0件 |
| エラー表示（#VALUE! など） | 0件 |
| ありえない1日量（3桁以上） | 0件 |
| 印刷が1枚に収まらない書類（A4・Letter） | 0件 |

- 直したこと：なし。提案：なし。
